# Preflight

대상 스킬의 정상 실행 경로를 처음부터 끝까지 따라가며, 실제 실행 전에 준비할 것과 실패할 지점을 찾습니다.

## 입력

- 점검할 `SKILL.md` 또는 워크플로우 문서 경로
- 사용자가 정한 목표와 실행 환경
- 문서가 직접 참조하는 스크립트, 설정, 템플릿

필수 경로나 목표가 없으면 그 정보가 필요한 점검만 보류하고, 읽을 수 있는 문서의 구조 점검은 계속합니다.

## 점검 절차

1. 대상 문서와 직접 참조 자산을 읽습니다.
2. 입력에서 최종 결과까지 정상 경로를 순서대로 적습니다.
3. 각 단계의 실행 주체, 입력, 출력, 외부 효과, 다음 단계 연결을 확인합니다.
4. 현재 환경에서 읽기 전용으로 확인할 수 있는 명령과 경로는 직접 확인합니다.
5. 실패 시 진행 상태를 보존하는지, 같은 외부 효과를 중복 실행할 수 있는지 확인합니다.
6. 기존 검증이 실제 결과를 확인하는지 보고, 빠진 검증만 제안합니다.

## 판정

- **준비됨**: 필수 입력과 도구가 있고 정상 경로와 검증이 이어집니다.
- **수정 필요**: 실행 전에 고칠 수 있는 구체적인 계약 또는 검증 공백이 있습니다.
- **차단됨**: 필수 입력, 권한, 도구가 없어 안전하게 시작할 수 없습니다.

근거가 없는 위험은 만들지 않습니다. 문서 표현보다 실제 스크립트와 현재 환경이 다르면 그 차이를 보고합니다.

## 출력

```text
결론: 준비됨 | 수정 필요 | 차단됨

필수 전제 조건:
- 확인할 항목과 확인 방법

실패 위험:
- 발생 조건 → 영향 → 방지 또는 복구 방법

검증:
- 실행 진입점 → 기대 결과

수정 제안:
- 필요한 경우에만 최소 변경
```

사용자가 수정을 요청하지 않은 점검에서는 대상 스킬과 스크립트를 바꾸지 않습니다.
