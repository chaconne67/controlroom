# kmh-agent-kit 조정실 문서

코드·실행 위치: 현재 조정실의 kmh-agent-kit 체크아웃이며 기본값은 `~/kmh-agent-kit`입니다. `~`는 Windows의 `USERPROFILE`, macOS·Linux의 `HOME`입니다.

공통 지침·스킬 원본은 기존 키트에서 버전 관리합니다. 서버에 남은 과거 키트와 미반영 작업을 덮어쓰거나 현행 정본으로 사용하지 않습니다.

2026-09-13에 보관 위치를 정리했습니다. 문서의 작성일·승인 상태·폐기 여부는 바꾸지 않았습니다. 원문 속 코드·명령 경로는 원래 서버 저장소 기준이며, 이전 위치와 SHA-256은 루트 provenance.json에 있습니다.

## 작업 기록

- [조정실 작업 환경 통합 계획](seamless-workspace-plan.md): 2026-09-13 완료했습니다. 지침·도구·프로젝트·현재 작업을 다른 장비에서 이어받는 통합 기능의 Windows·Linux·macOS CI, 최종 리뷰, 공개 main 게시와 현재 Windows 조정실 설치를 확인했습니다. 공개 판본과 별도 사용자 작업을 보존한 현재 PC 판본은 계획의 `재개 정보`에서 구분합니다.

이 계획의 `재개 정보`가 이번 작업의 완료 상태와 후속 작업 진입점입니다. 계획의 검증 근거와 실제 키트 Git 상태를 대조하고 다음 작업을 수행합니다. 병렬 작업이 추가되면 해당 계획의 링크와 재개 정보를 각각 유지합니다.
