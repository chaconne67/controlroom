# 믹스 평가액 손절 익일 체결 구현 계획

## 목표

- 리밸런싱일 종가로 새 포트폴리오를 확정하고 설정된 거래 지연 후 거래한다.
- 일별 포트폴리오 종가 평가액으로 전고점과 손절 신호를 계산한다.
- 손절 신호 다음 영업일에 목표 평가액 도달 여부에 따라 손절가격 또는 종가로 체결한다.
- 손절 매도금액에 `self.cost`를 반영한다.
- 실제 최종 경로를 호출하는 자동 테스트로 규칙을 고정한다.

## 현재 최종 경로

1. `Mix.main()`
2. 하위 AWT·BAA 백테스트 실행 및 결합
3. 믹스 비중 리밸런싱
4. `arrange_df()`로 일별 `Portfolio` 계산
5. `Mix.apply_losscut()`
6. `arrange_df()`로 최종 결과 정리

현재 믹스 리밸런싱은 `isRDay` 당일에 실행된다. 평가액 손절은 종가 하락을 감지한 당일 같은 종가로 즉시 현금화하며 거래비용을 차감하지 않는다.

## 변경 병합 위치

### 믹스 리밸런싱

- 현재 `Mix.main()` 내부 리밸런싱 단계를 기존 메서드로 승격한다.
- `isRDay`는 포트폴리오 확정일로 유지한다.
- 실제 비중 변경은 `isRDay.shift(self.trade_delay)`에 해당하는 거래일에 실행한다.

### 평가액 손절

- `Mix.apply_losscut()`의 평가액 손절 단계에 대기 상태를 둔다.
- 신호일 종가 `Portfolio`가 전고점 대비 손절률을 초과 하락하면 해당 종가 평가액을 목표 체결 평가액으로 저장한다.
- 신호일에는 보유수량을 변경하지 않는다.
- 원시 종가가 존재하는 다음 실제 거래일을 다음 영업일로 사용한다.
- 다음 영업일의 장중 최고 평가액이 목표 평가액 이상이면 목표 평가액으로 체결한다.
- 목표 평가액에 도달하지 못하면 다음 영업일 종가 평가액으로 체결한다.
- 기존 현금은 유지하고 실제 매도 대상 평가액에만 `self.cost / 100`을 차감한다.
- 리밸런싱일 종가에서는 기존 전고점과 손절 상태를 초기화하고 새 손절 신호를 만들지 않는다.

### 가격과 평가액

- 손절 신호와 전고점은 기존 `self.master_df['Portfolio']` 종가 평가액으로 계산한다.
- 종가 평가액은 기존 보유수량 × 조정종가 합산 경로를 재사용한다.
- 다음 영업일 장중 최고 평가액은 같은 보유수량에 조정 고가를 적용해 계산한다.
- 조정 고가는 `high × adjclose / close`로 계산한다.
- 휴장 종목은 해당 날짜의 조정종가를 사용해 전일 고가를 잘못 이월하지 않는다.

## 대체·정리 대상

- 평가액 손절 당일 현금전환 코드를 대기 신호와 익일 체결 코드로 대체한다.
- `Mix.main()` 내부 리밸런싱 함수를 테스트 가능한 기존 클래스 메서드로 대체한다.
- 임시 진단 코드와 별도 실행 스크립트는 남기지 않는다.
- 지수 기준 손절과 종목 기준 손절은 변경하지 않는다.
- 방어전환 기능과 화면은 변경하지 않는다.

## 자동 테스트

`portfolio_mix/tests.py`에서 실제 믹스 메서드를 합성 가격 데이터로 실행한다.

1. 리밸런싱 거래가 확정일이 아니라 다음 영업일에 실행된다.
2. 전고점과 손절 신호는 일별 종가 `Portfolio`로 계산된다.
3. 손절 신호일에는 매도하지 않는다.
4. 다음 영업일 최고 평가액이 목표 이상이면 신호일 종가 평가액으로 체결한다.
5. 다음 영업일 최고 평가액이 목표 미만이면 다음 영업일 종가 평가액으로 체결한다.
6. 정확히 목표 평가액에 도달해도 체결한다.
7. 손절 매도 대상 금액에 `self.cost`가 차감된다.
8. 리밸런싱일에는 기존 손절 상태가 초기화되고 새 신호가 발생하지 않는다.
9. 손절 후 다음 리밸런싱 거래일까지 현금을 유지한다.
10. 기존 현금에는 거래비용을 부과하지 않는다.
