## 의미에 따른 배점 강도

배점은 연령처럼 간접적인 요인보다 현재 상품 위험을 이해하는 능력, 손실을 감당할 자금 여력, 실제 사용 시점을 더 강하게 반영하도록 정했다. 아래 최고 성향은 법정 의무나 타사의 배점이 아니라 이번 설계에서 선택한 보수적인 기준이다.

| 요인 | 설계 기준 |
|---|---|
| 65세 이상 또는 20세 미만 | 같은 -3점. 나이만으로 특정 성향에 고정하지 않고 다른 응답을 함께 반영한다. |
| 금융투자상품 경험 없음 | 상품 종류에서 가점 0점, 경험 기간에서 -5점. 두 문항 모두에 음수 배점을 주지는 않는다. 경험이 없다는 사실만으로 공격형이 되지는 않게 한다. |
| 기초적인 수익·손실 구조 이해 부족 | 다른 응답이 모두 최고점이어도 위험중립형 이하가 되도록 -22점. 높은 소득이나 상품 매매 경험만으로 지식 부족이 상쇄되지 않게 한다. |
| 감수 가능한 손실이 작음 | 5% 이하는 기존 안정형 제한과 점수가 일치하도록 -43점. 5~10%는 위험중립형 이하, 10~15%는 적극투자형 이하가 되도록 반영한다. |
| 생활비·대출 상환에 투자금 필요 | 손실이 필수 지출에 직접 영향을 주므로 다른 응답이 모두 최고점이어도 안정추구형 이하가 되도록 -34점. |
| 6개월 안에 사용할 투자금 | 변동을 견딜 시간이 짧으므로 다른 응답이 모두 최고점이어도 위험중립형 이하가 되도록 -22점. |

## 환산과 성향 구간

기존 코드를 그대로 사용한 계산식:

```text
원점수 = 선택지별 새 배점의 합
환산점수 = round(min(100, max(0, 원점수 / 64 * 100)))
```

Python round의 0.5 짝수 반올림도 그대로다. 새로운 음수 최저점을 0점으로 끌어올리는 최소·최대 재정규화는 하지 않는다. 그러면 감점의 효과가 없어지고 기존 점수 구간의 뜻도 달라지기 때문이다.

| 성향 | 기존 그대로 사용하는 환산점수 구간 |
|---|---|
| 안정형 | 0~25 |
| 안정추구형 | 26~39 |
| 위험중립형 | 40~59 |
| 적극투자형 | 60~79 |
| 공격형 | 80~100 |

총점에 따른 성향을 정한 뒤 기존 1·7·8번 응답의 상한을 적용한다. 상한은 성향을 낮추는 경우에만 적용하며 더 낮은 점수의 성향을 올리지 않는다.

## 큰 음수 배점을 정한 계산 근거

대상 문항을 제외한 다른 문항의 최고점 합계는 59점이다. 따라서 원점수에서 -3~-5점만 주면 중요한 위험 요인이 있어도 높은 성향으로 올라갈 수 있다. 먼저 응답의 의미에 맞는 최고 성향을 정하고, 그 조건을 만족하는 배점을 계산했다.

| 목표 | 배점 | 다른 문항 최고점일 때 계산 | 최고 환산점수 |
|---|---:|---|---:|
| 기존 안정형 제한을 점수에도 반영 | -43 | (59 - 43) / 64 × 100 | 25 |
| 필수 지출에 투자금이 필요한 경우 안정추구형 이하 | -34 | (59 - 34) / 64 × 100 | 39 |
| 손실 5~10%, 기초 지식 부족, 6개월 미만의 자금은 위험중립형 이하 | -22 | (59 - 22) / 64 × 100 | 58 |
| 손실 10~15%는 적극투자형 이하 | -9 | (59 - 9) / 64 × 100 | 78 |

위험중립형 이하만 충족하는 정수 배점은 -21점(최고 59점)도 가능하다. 이번에는 -22점으로 1점 더 보수적으로 정했다. 6개월~1년, 1년 이내 예정 지출, 낮은 기초 이해의 -10점도 적극투자형 상한을 만족하는 -9점보다 1점 보수적으로 둔 값이다. 경계값과 실제 선택한 여유를 구별한다.

연령 -3점과 경험 기간 -5점은 특정 등급을 강제하기보다 결합 효과를 반영하도록 정했다. 연령만 해당하면 최고 89점, 경험이 전혀 없으면 5·6번을 합산해 최고 77점이다. 따라서 연령만으로 공격형을 배제하지 않으며, 경험 없음은 공격형에 도달하지 않는다.

- 각 선택지 조합 수를 원점수와 기존 상한별로 묶어 정확히 계산했다. 5^13 = 1,220,703,125개 조합 전체에서 5개 성향 모두 도달 가능하고 0~100 범위를 벗어나지 않는다.

### 검증의 한계와 보수성

모든 선택지 조합에 동일한 가중치를 준 계산에서 안정형 972,838,412개(79.69%), 안정추구형 123,572,003개(10.12%), 위험중립형 82,397,095개(6.75%), 적극투자형 39,442,546개(3.23%), 공격형 2,453,069개(0.20%)다. 이 가운데 환산점수 0점은 668,698,197개(54.78%)다.

이 수치는 실제 고객 분포가 아니다. 경험 없음과 5년 이상 경험처럼 동시에 성립하기 어려운 조합도 포함하며, 답변별 빈도가 같다는 가정도 실제 고객 자료로 확인하지 않았다. 강한 감점이 여러 개 겹치면 같은 안정형·0점으로 모인다는 구조적 성질을 보여 주는 점검 결과다. 실제 응답 자료에 대한 통계적 적합성이나 심사기관의 승인까지 검증했다고 주장하지 않는다.
