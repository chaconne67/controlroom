# 투자성향 설문 최종 문구 수정안 (2026-09-21)

상태: 코드 수정·검증·원격 저장소 반영·3차 두 전략 별첨 업로드 완료. 운영 배포 및 심사 포털 제출은 별도. 이 문서가 현행 작업 정본이며, 앞선 의미검토 문서의 9문항·40점안과 12문항·50점안은 채택하지 않는다.

## 적용 기준과 잠금

1. 최상위 기준: 주인님이 2026-09-21 첨부한 '개인 맞춤성 I' 심사표와 과거 심사 이메일의 취지.
2. 최신 지시: 심사 기준에 맞는 질문 구조, 기존 점수 체계, 타사 설문을 참고한 합리적이고 부드러운 질문·선택지.
3. 기존 13문항·65개 선택지·문항별 배점·원점수 최대64·최소13·100점 환산·유형 점수대 유지.
4. 문항마다 하나 선택, 5번 상품 예시를 여러 개 경험해도 배점은 한 번만 합산. 9번은 기존대로 20세 미만과 65세 이상 모두1점. 이해 부족/경험 없음은 최저점.
5. 기존 환산식 round(원점수/64×100) 유지. Python round의 0.5 짝수 처리 포함. 점수대: 안정형≤25, 안정추구형26~39, 위험중립형40~59, 적극투자형60~79, 공격형≥80.
6. 최종 추가 지시가 앞선 권장안 승인을 대체한다. 점수·판정·성향 점수대를 모두 기존 그대로 유지한다. 7·8번 첫 선택지는 안정형, 1번 첫 선택지는 안정추구형 이하로 제한하며 중복 시 안정형을 우선한다. scoring.py는 작업 시작 HEAD 원문 그대로 보존한다.
7. 범위: 원격 userprofile 문항 정의·설문·배점표·결과 설명·별첨 생성기 및 3차 국내ETF/퇴직연금의 별첨 PPTX/PDF. 운영 배포·DB·주문·환경·예약·인증·포털 제출 제외.
