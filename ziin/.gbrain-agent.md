# ZiiN GBrain

전역 `~/.gbrain-agent.md`의 공용 `default` 소스와 공식 조회 명령을 먼저 따른다. 작업 전 `project/ziin-operating-context`를 읽고, 관련 작업에 따라 다음 문서를 확인한다.

- 랜딩·문구·디자인: `project/ziin-landing-page`, `feedback/ziin-copy-and-design-rules`, `project/ziin-design-assets`
- 챗봇·배포: `project/ziin-chatbot-deploy`

제품 기능을 다룰 때는 관련 Exdigm 문서와 실제 운영 코드도 확인한다. 검증된 실제 코드·운영 상태, 최신 사용자 결정과 작업 지시, 프로젝트 문서, GBrain 순으로 판단한다.

검증된 사실, 반복할 결정, 사용자 피드백, 재현·원인이 확정된 디버깅 결과만 기록한다. 원문 로그·대화 전문·비밀값·개인정보·검증되지 않은 추측은 기록하지 않는다. 디버깅 문서는 재현 조건과 근본 원인이 확정된 뒤에만 만든다.
