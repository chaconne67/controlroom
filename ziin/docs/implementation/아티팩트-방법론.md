# 아티팩트 방법론

메시지 → 소재 선택 → 표현 방식 → 배치·디테일. 이 네 단계를 정리한 문서다.
참조: syllabus.io · userinterviews.com · clerk.com · popcorn.space (전부 실제 화면을 캡처해 분석)

---

## 1. 네 단계

```
① 이 섹션이 하려는 말이 무엇인가        → 메시지
② 그 말을 무엇으로 보여줄 것인가        → 소재
③ 그 소재를 어떤 형태로 그릴 것인가     → 표현
④ 어디에 어떻게 놓고 무엇으로 채울 것인가 → 배치·디테일
```

**대부분의 실패는 ②에서 난다.** 메시지가 "밤에도 일한다"인데 낮 업무 화면을 넣는 식이다. 소재가 메시지를 배신하면 ③④를 아무리 잘해도 소용없다.

## 2. 소재 카탈로그 — 무엇을 쓸 수 있나

| 소재 | 무엇 | 언제 쓰나 | 사례 |
|---|---|---|---|
| **실사 사진** | 사람 얼굴, 현장 | 신뢰·감정. 후기, 인물 | userinterviews 후기, clerk 역할 그리드 |
| **제품 UI 목업** | 실제 화면 또는 재현 | 능력 증명. "진짜 있는 물건이다" | clerk 로그인 카드, popcorn 앱 화면 |
| **벡터 문서 조각** | 문서를 추상화한 그림 | 문서·데이터가 주제일 때 | syllabus 전면 |
| **라인아트 카툰** | 손그림 인물·사물 | 감정·관계·재미 | userinterviews 히어로 |
| **기기 목업** | 폰·노트북 프레임 | 모바일·현장성 | popcorn 폰 |
| **브라우저 창** | 크롬 바 + 화면 | 웹·외부 사이트 | 지인 사이트 여섯 곳 |
| **아이콘 조합** | 서비스 로고가 모이는 그림 | 연동·다중 채널 | clerk Social SSO |
| **데이터 그래픽** | 도넛·막대·퍼센트 | 수치·분석 | syllabus 전면 |
| **로그·타임라인** | 시각 + 사건 행 | 시간·자동 처리 | clerk Fraud 감지 |
| **아바타 그리드** | 얼굴 격자 | 조직·역할·인원 | clerk 역할 배정 |
| **텍스트만** | 그림 없음 | 쉬는 구간, 인용, 통계 | userinterviews 통계 띠 |

## 3. 메시지 유형 → 소재 매칭

| 메시지 성격 | 맞는 소재 | 틀린 소재 |
|---|---|---|
| **연결·관계** | 흐르는 선이 둘을 잇는 라인아트 | 정적인 카드 나열 |
| **시간·자동 처리** | 시각이 찍힌 로그 행, 시계 | 기능 목록 |
| **속도·경쟁** | 같은 축 위의 두 줄, 동시 게시 창 | 아이콘 하나 |
| **능력 증명** | 실제 UI 목업 | 일러스트 |
| **신뢰** | 실사 얼굴 + 별점 + 로고 | 추상 도형 |
| **감정·보상** | 카툰 인물 | 스크린샷 |
| **수치·사실** | 모노스페이스 텍스트, 얇은 프레임 | 큰 그림 |
| **절차** | 번호 + 아이콘 + 구분선 | 문단 |
| **문서 품질** | 전/후 문서 두 장 | 체크 목록 |
| **분해·구조화** | 덩어리 → 조각으로 갈라지는 도식 | 표 |

## 4. 풍성함을 만드는 기법 12가지

실제 사례에서 뽑았다. 지금 지인 시안에 부족한 것들이다.

### 4-1. 조각을 여러 개 띄운다 — syllabus

문서 한 장을 크게 넣지 않는다. **작은 조각 3~5개를 크기와 각도를 달리해 흩어 놓는다.**
- 흰 카드 + 1px 외곽선
- 안의 글자는 **색 막대**로만 (남색 = 본문, 노랑 = 강조, 코랄 = 경고)
- 도넛 차트, 막대 그래프, 퍼센트 숫자를 섞는다

### 4-2. 딱딱한 오프셋 그림자 — syllabus

blur 없는 **단색 사각형을 카드 뒤에 어긋나게** 깐다. 흐린 그림자보다 인쇄물 같고 값싸 보이지 않는다.

### 4-3. 점선으로 조각을 잇는다 — syllabus

흩어진 조각을 **점선 + 관절의 작은 원**으로 연결한다. 낱개가 아니라 **하나의 시스템**으로 읽힌다.

### 4-4. 선명한 하나 + 흐릿하게 쌓인 여럿 — clerk

주인공 UI 한 장을 선명하게 앞에 두고, **같은 종류를 뒤에 흐리게(blur + 낮은 투명도) 겹쳐 쌓는다.** 깊이가 생기고 "이런 게 많다"가 말 없이 전달된다.

### 4-5. 베이토 그리드 + 카드마다 다른 그래픽 — clerk

한 섹션에 카드 6~9장. **카드마다 그래픽 종류를 전부 다르게** 한다. 클럭의 인증 섹션은 사각형 나열 / 기기 행 / 아이콘 격자 / 로그 타임라인 / 아이콘 수렴 / 지문 / 점 흩뿌림이 한 화면에 있다.

### 4-6. 딱 한 곳만 채도를 올린다 — clerk

무채색이 압도적이고(`#131316` 269회) 포인트 시안(`#64E5FF`)은 23회뿐이다. 다크 섹션에서 **빛나는 지문 하나**만 색을 갖는다. 시선이 거기로 간다.

### 4-7. 옅은 배경 패턴으로 빈 곳을 채운다 — clerk

히어로 배경에 **아주 흐린 회로도 패턴**을 깐다. 의미는 없지만 dull 함이 사라진다.
그라데이션도 alpha 0.04~0.25 범위로만 쓴다.

### 4-8. 일러스트 안에 실사를 박는다 — userinterviews

손그림 라인아트 한가운데에 **실제 인물 사진을 동그란 아바타로** 넣는다. 두 소재의 혼합이 화면을 살린다.

### 4-9. 선이 메시지를 그린다 — userinterviews

"We connect"라는 메시지에서 **곡선이 화면을 가로질러 두 사람을 실제로 연결한다.** 메시지를 설명하지 않고 선이 대신 그린다.

### 4-10. 섹션마다 배경색을 바꾼다 — userinterviews

흰 → 베이지 → 흰 → 하늘 → 흰 → 자주 → 흰 → 남색. **배경 리듬만으로 지루함이 사라진다.**

### 4-11. 떠 있는 배지와 툴팁 — clerk · popcorn

카드 모서리 밖으로 **작은 알약 배지**가 걸쳐 나온다. "Invite this person", "Yes, we timed it." 같은 것. 화면에 손이 간 느낌을 준다.

### 4-12. 미세 모션 — clerk

`450ms cubic-bezier(0.33, 1, 0.68, 1)`
- 호버에서 카드가 2~4px 뜬다
- 떠 있는 요소가 6~8초 주기로 아주 느리게 부유한다
- 진입할 때 순차로 떠오른다 (지연 60ms 간격)
- 가로 스윕 그라데이션이 지나간다

## 5. 배치 패턴

| 패턴 | 언제 |
|---|---|
| 좌 텍스트 / 우 아티팩트 교대 | 기본. 3개 이상 이어질 때 좌우를 번갈아 |
| 중앙 정렬 + 아래 큰 목업 | 히어로 |
| 가운데 제목 + 둘러싼 카드 8장 | 기능 나열. 알약 목록의 대체 |
| 베이토 그리드 | 한 주제의 여러 면을 보일 때 |
| 풀블리드 띠 | 로고 월, 통계 |
| 텍스트만 | 스토리·인용. **쉬는 구간이 있어야 나머지가 산다** |

## 6. 채도·디테일 전략

```
넓은 면      무채색 또는 아주 낮은 채도
작은 요소    배지·체크·아바타·상태 점만 채도를 올린다
그라데이션   alpha 0.04 ~ 0.30
질감         점 격자 또는 노이즈를 opacity 0.5 이하로
```

**dull 하다는 느낌은 대개 "빈 곳이 그냥 비어 있어서" 생긴다.** 의미 없는 옅은 워시 하나, 질감 하나로 대부분 해결된다. 단 난잡해지면 역효과다 — 한 섹션에 워시는 두 개까지.

## 7. 지인 각 섹션에 적용

| 섹션 | 메시지 | 소재 | 표현 |
|---|---|---|---|
| 히어로 | 퇴근 후에도 일한다 | **시각이 찍힌 로그** + 제품 화면 | 화면 밖으로 떠 있는 야간 알림 카드 3장. 부유 모션 |
| 개요 ① | 지루한 일을 가져간다 | 체크리스트 UI | 넷에 취소선, 하나만 남김 |
| 개요 ② | 먼저 연락하면 이긴다 | **실제 사이트 여섯 창** | 동시 게시 + 초록 체크 배지 |
| 개요 ③ | 말하듯 시킨다 | **폰 기기 목업** | 상태바·아바타·시각·마이크까지 |
| 페인 ① | 이력서 고치다 하루 | **전/후 문서 두 장** | 삐뚤한 것 vs 정렬된 것 |
| 페인 ② | 고객사 이름이 올라갔다 | 검사 카드 | 취소선 + 제외됨 배지 |
| 페인 ③ | 더미에 숨어 있다 | **분해 도식** | 파일 더미 → 항목 행 |
| 실화 | 여기서 시작했다 | **텍스트만** | 세리프. 쉬는 구간 |
| 그 밖에 | 필요한 건 다 있다 | **미니 UI 8개** | 가운데 제목 + 둘러싸기 |
| CTA | 오늘부터 | 없음 | 어두운 블록 + 광택 |

### 아직 안 한 것

- **실사 인물 사진** — 후기 섹션을 만들면 반드시 필요하다. 지금 지인에는 사진 자산이 없다
- **syllabus식 벡터 문서 조각** — 페인 ①③을 이 방식으로 다시 그리면 더 살 수 있다
- **점선 연결** — 흩어진 조각을 하나의 시스템으로 묶는 장치
- **선명 + 흐릿한 겹침** — 제품 화면 여러 장을 뒤에 쌓는 기법
- **로고 월** — 도입 고객사가 생기면
