# CRETOP

## 실행 원칙

- 조정실 Windows에서 사용자의 화면을 방해하지 않아야 하면 `$hidden-desktop-browser`를 함께 적용하고 실제 Chrome 화면을 먼저 읽습니다.
- 사용자가 현재 화면에서 직접 보거나 조작하기를 원하면 지정한 브라우저·컴퓨터 조작 도구를 사용합니다.
- 세션 URL, 창 크기, 화면 좌표를 재사용하지 않습니다. 보이는 글자와 현재 조작 가능 상태로 대상을 찾습니다.
- 로그인 정보는 입력하지 않습니다. 로그인 화면을 연 뒤 사용자가 직접 로그인할 때까지 기다립니다.
- 조회 조건을 바꾸거나 다운로드를 시작하기 전에 현재 선택값과 사용자의 요청을 대조합니다.
- 화면이나 사이트가 바뀌어 기존 기록과 다르면 현재 화면을 정본으로 삼고 차이를 보고합니다.

## 로그인 화면 열기

사용자가 로그인 화면을 준비해 달라고 하면 CRETOP 전용 프로필로 `https://www.cretop.com/`을 엽니다. 사람이 로그인해야 하는 단계만 보이는 화면에서 진행하고, 로그인 뒤에는 같은 프로필을 숨은 데스크톱으로 이어서 사용합니다. 사용자가 로그인을 마쳤다고 알린 뒤에만 다음 조작을 시작합니다.

## 화면 조작

1. 현재 탭 제목과 로그인 상태를 확인합니다.
2. 메뉴와 버튼은 접근성 이름 또는 보이는 글자로 찾습니다.
3. 클릭 직전에 대상이 실제로 조작 가능한지 확인합니다.
4. 클릭 뒤 제목, URL, 선택 표시 또는 결과 건수처럼 직접 바뀐 상태를 확인합니다.
5. 팝업이 가리면 팝업의 닫기 버튼을 찾아 닫고 같은 단계를 다시 확인합니다.

로그인, 약관, 결제, 추가 인증처럼 사용자 판단이 필요한 화면은 사용자에게 넘깁니다.

## 스마트검색

사용자가 상세 조건을 요청하면 `references/smart-search-conditions.md`의 화면 이름과 값 매핑을 참고하되, 실제 화면에서 같은 이름과 값인지 다시 확인합니다.
