# Thock 제품 방향

- 작성일: 2026-09-26
- 상태: **방향 합의 중** (구현 미승인)
- 관련: [Store 글로벌 구독 출시 계획](Store-출시-계획-2026-09-26.md), [음성입력 마스터플랜](음성입력-마스터플랜-2026-09-26.md)

## 1. 한 줄 정의

**Thock: 대충 말해도 제대로 알아듣고 받아 적는, 받아쓰기 하나만 깊게 파는 앱.**

- 기능을 넓히지 않습니다.
  - 넣지 않는 것: 명령 실행, 메일 답장 쓰기, 번역 모드, 회의 녹음
  - 경쟁 앱(Flow·WhisperTyping)은 이런 기능을 늘려 가지만 Thock은 따라가지 않습니다.
- 모든 추가 기능은 **"받아쓰기가 더 정확해지는가"** 하나로 판단합니다.

## 2. 주인님이 겪은 경쟁 앱의 문제 → Thock의 원칙

| 겪은 문제 | Thock의 원칙 | 확인 기준 |
|---|---|---|
| Flow가 한국어를 잘 못 알아들음 (영어 중심) | 언어마다 같은 품질. 영어 중심 기능을 만들지 않음 | 언어별 시험 문장으로 정확도 측정 |
| WhisperTyping이 하루 한두 번 고장 나 껐다 켜야 함 | **스스로 복구**: 키 가로채기가 풀리면 다시 설치, 마이크가 바뀌면 다시 연결, 네트워크가 끊기면 다시 시도 | 하루 종일 켜 두고 재시작 0회 |
| 디자인이 엉망, 쓸데없는 설정이 많음 | 설정은 6개 이하, 표시는 글자 없는 작은 알약 하나 | 설정 창 항목 수 |
| 업데이트가 안 됨 | Store 자동 업데이트 | — |
| 무겁고 켜는 데 오래 걸리고 다른 프로그램까지 버벅임 | **가벼움 예산**: 메모리 60MB 이하, 대기 CPU 1% 이하, 켜지는 데 1초 이내 | 지금 측정: 메모리 약 31MB, 대기 CPU 0.3% |

- "스스로 복구"의 근거
  - Windows는 키 가로채기 프로그램이 잠깐이라도 응답을 늦추면 **알리지 않고 가로채기를 해제**합니다.
  - 이런 앱이 "가끔 갑자기 안 먹히는" 흔한 원인입니다.
  - Thock은 이를 주기적으로 확인해 다시 설치합니다.

## 3. 더 잘 받아 적기 위한 기능 두 가지

두 기능 모두 **학습 내용은 사용자 PC 안에만 암호화해 저장**합니다. 사용자가 보고 지울 수 있습니다.

### 3-1. 나를 아는 받아쓰기 (맥락 학습)

같은 말도 분야마다 적는 법이 다릅니다.
- 예: "피알"은 개발자에게는 PR(Pull Request)이고, 마케터에게는 홍보(PR)입니다.
- 예: "셀"은 엑셀을 쓰는 사람에게는 칸이고, 생물학자에게는 세포입니다.

Thock은 사용자가 어떤 분야의 사람인지 알고 받아 적습니다.

| 단계 | 내용 |
|---|---|
| 모으기 | 교정까지 끝난 최종 글을 PC에 암호화해 보관 (켜기/끄기 가능) |
| 추정하기 | 받아쓰기 50회마다 최근 글을 AI로 요약해 **나의 프로필**을 만듦. 분야·직업 추정, 자주 쓰는 고유명사·전문용어(최대 약 200개), 언어를 섞는 습관 |
| 쓰기 ① 인식 단계 | 프로필을 Soniox 맥락 정보로 넘김. `general`에 분야·주제(10개 이하 권장), `terms`에 용어. 한도는 8,000토큰. 인식 단계에서 바로 맞게 들림 → 효과가 가장 큼 |
| 쓰기 ② 교정 단계 | 같은 프로필을 교정 지시문에 넣음 |
| 지금 앱 맥락 | 지금 쓰는 앱(VS Code·Slack·메일 등)과 창 제목으로 말투·용어를 맞춤 |
| 보기·고치기 | 설정 창의 "Thock이 아는 나"에서 분야와 용어를 보고 고치거나 지움 |

- 교정 지시 원칙은 지금과 같습니다. 뜻을 해석하거나 바꾸지 않고, 맞게 **적는 데**만 맥락을 씁니다.

### 3-2. 오타 노트 (내가 고친 것을 기억)

주인님이 지금 쓰는 방식을 그대로 기능으로 만듭니다. 말하고, 받아 적은 글을 한번 보고, 틀린 단어만 고칩니다.

| 단계 | 내용 |
|---|---|
| 알아채기 | 붙여 넣은 뒤 입력칸의 글을 Windows 화면 읽기 기능(UI Automation)으로 다시 읽음. 시점은 Enter 직전, 다른 곳으로 이동할 때, 몇 초 뒤 |
| 찾기 | 붙여 넣은 글과 비교해 **짧은 단어 바꿈**만 오타 후보로 기록. 예: 펀드키퍼 → FundKeeper. 뒤에 이어 쓴 글은 무시 |
| 확정 | 같은 고침이 2번 나오면 오타 노트에 올림 |
| 쓰기 | ① 올바른 단어를 인식 용어로 넘김 ② 교정 지시문에 "X로 들리면 Y" ③ 확실한 것은 붙여 넣기 전에 자동으로 바꿈 |
| 관리 | 설정 창에서 오타 노트를 보고, 지우고, 직접 추가 |

- 한계: 화면 읽기로 입력칸 글을 읽을 수 없는 앱에서는 자동으로 알아채지 못합니다. 원격 데스크톱이나 일부 특수 앱이 그렇습니다.
  - 이런 앱은 직접 추가로 보완합니다.
  - 어느 앱에서 되는지는 먼저 시험합니다. 대상: Claude, Chrome, 카카오톡, 터미널, VS Code, 메모장.
  - 터미널과 메모장은 이미 이 방법으로 글을 읽어 확인했습니다.

## 4. 언어

Soniox 실시간 모델은 **60개 언어**를 인식합니다(API 조회로 확인).

- 인식은 60개 언어 전부 처음부터 됩니다.
- 아래 목록은 **앱 화면·Store 목록을 번역해 공략할 나라**입니다.

### 추천 출시 언어 (12개)

| 묶음 | 언어 | 이유 |
|---|---|---|
| 자판이 불편한 문자 (핵심) | 한국어 | Flow가 약함. 한국어 품질이 차별점 |
| | 일본어 | 가나·한자 변환 입력이 번거로움. Aqua Voice 사용자 절반 이상이 일본 → 수요 확인됨 |
| | 중국어 간체·번체 | 병음 입력 후 한자 선택이 번거로움. 번체는 대만·홍콩 |
| | 베트남어 | 성조 기호 입력(Telex)이 번거로움 |
| | 태국어 | 자모가 많아 자판이 복잡함 |
| | 힌디어 | 데바나가리 문자 입력이 어려워 대부분 영어 자모로 적음. 음성 입력 수요 큼 |
| 큰 시장 | 영어 | 가장 큰 시장 |
| | 스페인어 | 중남미·스페인 |
| | 포르투갈어(브라질) | 큰 Windows 사용자층 |
| | 인도네시아어 | 큰 인구, 성장 시장 |
| | 독일어 | 구매력 큰 유럽 시장 |

- **2차 후보**
  - 아랍어·페르시아어·우르두어·히브리어: 오른쪽→왼쪽 문자라 설정 창을 좌우 반전해야 해서 따로 합니다.
  - 벵골어·타밀어·텔루구어, 터키어, 프랑스어, 러시아어
- **주인님 가설 "문자가 불편한 나라에서 잘 먹힐 것"은 근거가 있습니다.**
  - 이런 언어는 자판 입력이 느려서, 말로 쓰면 아끼는 시간이 영어보다 큽니다.
- **주의할 점**
  - 중국: 현지 강자(讯飞 등)가 PC 음성 입력을 무료로 제공하고, 해외 서비스 접속이 불안정할 수 있습니다. 출시는 하되 기대치는 낮게 잡습니다.
  - 구매력이 낮은 나라: 원가는 어디서나 녹음 1시간에 약 $0.19로 같습니다. 나라별 가격을 너무 낮추면 손해가 납니다. 가격 하한을 둡니다.
  - 지원 안 되는 언어: 미얀마어·크메르어·라오어 등은 Soniox 목록에 없어 제외합니다.

## 5. 이름: Thock

- **겹침**
  - 같은 이름의 **Mac용 키보드 타건음 앱**이 있습니다.
    - 무료·오픈소스이고 Mac App Store에 있습니다.
    - 주소는 thockapp.com입니다.
  - 키보드라는 같은 분야라 헷갈릴 수 있습니다.
- **Windows Store**: 그 앱은 Windows판이 없어서 Microsoft Store에서는 이름 예약이 될 가능성이 있습니다. Partner Center에서 확인해야 합니다.
- **대안**
  - Store 표시 이름을 **"Thock Voice"** 또는 **"Thock — Voice Typing"** 으로 하면 구분되고 검색에도 유리합니다.
  - 도메인도 이 이름으로 정합니다. 예: thockvoice.com
- **상표**: 등록 여부는 주인님이 따로 확인하시는 것이 안전합니다.

## 6. 진행 순서 제안

**학습 기능을 Store 작업보다 먼저, 지금 이 PC의 개인판에 넣습니다.**

- 주인님이 매일 쓰는 첫 사용자라서, 정확도가 나아지는지 며칠 안에 확인할 수 있습니다.
- Store·구독·서버는 기능이 검증된 뒤 올리는 포장입니다.

| 단계 | 내용 | 확인 |
|---|---|---|
| A-1 | 안정성: 키 가로채기 자동 복구, 마이크 재연결, 네트워크 재시도 | 하루 종일 재시작 0회 |
| A-2 | 오타 노트: 앱별 입력칸 읽기 시험 → 고침 알아채기 → 반영 | 주인님이 고친 단어가 다음부터 맞게 나옴 |
| A-3 | 맥락 학습: 프로필 추정 → 인식·교정에 반영, 앱 맥락 | 같은 시험 문장의 틀린 단어 수 감소 |
| A-4 | 다국어: 언어 설정, 교정 지시문 영어화 | 영어·일본어 등 시험 문장 |
| B | Store 글로벌 구독 출시 계획 1~5단계 | 그 계획의 완료 기준 |

## 6-1. 진행 기록

- **2026-09-27 결정 (주인님)**
  - Store 표시 이름: **Thock Voice Typing**
  - A 단계부터 시작합니다.
- **2026-09-27 완료: 표시·설정 창·A-1 안정성**
  - 표시
    - 평소에는 작업 표시줄 4px 위 화면 가운데에 작은 막대만 둡니다.
    - 마우스를 올리면 알약과 톱니바퀴(설정)가 뜹니다.
    - 오른쪽 클릭 메뉴: 설정 / 위치 초기화 / 종료
    - 끌어서 옮기면 위치를 기억합니다.
    - 눌러도 쓰던 입력창의 초점을 빼앗지 않습니다.
  - 설정 창 1차
    - 항목: 단축키, AI 교정, 용어 사전, API 키와 연결 확인, 위치 초기화
    - 로컬 서버(127.0.0.1, 실행마다 새 비밀값)와 Edge 앱 창으로 띄웁니다.
    - 저장하면 바로 적용됩니다.
    - 키가 없으면 켤 때 자동으로 열립니다.
  - A-1 안정성
    - 키 가로채기를 30초마다 다시 걸어, Windows가 몰래 푼 경우에도 복구합니다.

    - Soniox 연결 실패 시 최대 3번 다시 시도합니다. 녹음은 그동안 계속 쌓아 둡니다.
  - 확인 (격리 밖 실행판, 화면 캡처)
    - 기본 위치, 마우스 오버, 톱니바퀴 → 설정 창

    - 설정 API 접근 차단(비밀값·주소 검사)
    - CapsLock 받아쓰기(인식 0.31~0.41초), 대문자 고정
    - 대기 CPU 0.3%, 메모리 56MB
- **남은 확인**
  - 하루 종일 켜 두고 재시작이 필요 없는지: 주인님 실사용으로 확인합니다.
