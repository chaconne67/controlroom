# 엑스다임 스토리형 마케팅 카피 초안

> 작성 기준일: 2026-08-13  
> 활용 채널: 소개 리플렛, 랜딩 페이지, 이메일, 인스타그램 카드뉴스, 쇼츠 영상  
> 목적: 기능을 나열하지 않고, 헤드헌팅 현장의 문제와 엑스다임이 만드는 변화를 짧은 이야기로 전달한다.

## 1. 전체 메시지의 중심

### 엑스다임을 한 문장으로

> **엑스다임은 JD가 들어온 순간부터 후보자를 찾고, 추천 서류를 만들고, 채용공고를 게시할 때까지 헤드헌팅의 반복 업무를 하나로 연결하는 AI 업무 플랫폼입니다.**

### 가장 먼저 기억시킬 문장

> **AI가 준비하고, 헤드헌터가 결정합니다.**

### 전체 업무를 잇는 문장

> **한 장의 JD가 하나의 프로젝트가 되고, 회사에 쌓인 이력서가 적합 후보가 되고, 오늘 들어온 새 이력서가 내일의 새로운 후보가 됩니다.**

### 광고 표현 원칙

- 엑스다임은 후보자를 대신 결정하지 않는다.
- 엑스다임은 자료를 읽고, 정리하고, 후보를 좁히고, 문서를 준비한다.
- 후보자 선택, 고객사 추천, 발송과 채용 결정은 사람이 한다.
- 확인되지 않은 시간 절감률이나 성공률은 사용하지 않는다.

## 2. 대표 스토리 A — JD 한 장에서 시작되는 채용

### 추천 용도

- 랜딩 페이지의 메인 스토리
- 8장 카드뉴스
- 35~45초 쇼츠
- 리플렛의 앞면부터 뒷면까지 이어지는 전체 흐름

### 메인 카피

> # JD 한 장이 도착했습니다.  
> # 이제 몇 개의 일을 다시 해야 할까요?

### 이야기

고객사에서 새로운 JD가 도착합니다.

예전에는 프로젝트를 만들고, 조건을 다시 읽고, 폴더와 엑셀을 뒤지고, 채용 사이트마다 같은 공고를 다시 입력해야 했습니다.

엑스다임에서는 JD가 하나의 프로젝트로 이어집니다.

프로젝트 조건에 맞는 후보를 기존 인재풀에서 먼저 찾고, 더 찾고 싶은 후보는 평소 쓰는 말로 검색합니다.

> “반도체 공정 경험이 있고, 영어가 가능한 팀장급 후보자.”

컨설턴트가 후보자를 선택하면 연락부터 사전 미팅, 추천, 면접, 클로징까지 하나의 흐름으로 이어집니다.

고객사에 보낼 추천 이력서는 후보자 데이터와 양식으로 준비하고, 채용공고는 JD를 바탕으로 사이트별 자료를 만들어 게시 업무까지 연결합니다.

그 사이 이메일로 새 이력서가 들어오면 엑스다임이 이력서 자료를 찾아 후보자 데이터로 정리합니다.

오늘 들어온 이력서는 다음 프로젝트에서 다시 검색되는 회사의 자산이 됩니다.

### 결론 카피

> **한 장의 JD에서 한 명의 입사까지.**  
> **흩어진 일을 하나의 흐름으로 연결하세요.**

### CTA 후보

- 엑스다임의 한 번에 이어지는 업무 흐름 보기
- 새로운 프로젝트를 더 빠르게 시작해 보세요
- 회사의 인재풀을 실제 업무에 연결하세요

### 8장 카드뉴스 구성

1. **JD 한 장이 도착했습니다.**
2. **프로젝트 등록, 후보자 검색, 추천 서류, 채용공고. 또 처음부터 해야 할까요?**
3. **엑스다임은 JD를 헤드헌팅 프로젝트의 시작점으로 연결합니다.**
4. **프로젝트 조건에 맞는 후보를 회사의 인재풀에서 먼저 찾습니다.**
5. **더 찾고 싶다면 원하는 후보를 말하듯 검색합니다.**
6. **선택한 후보의 연락부터 면접과 클로징까지 한곳에서 이어집니다.**
7. **추천 이력서와 채용공고도 같은 정보에서 준비됩니다.**
8. **AI가 준비하고, 헤드헌터가 결정합니다. 엑스다임.**

## 3. 대표 스토리 B — 파일은 많지만 후보자는 찾을 수 없다

### 추천 용도

- 문제 인식형 광고
- 후보자 검색 기능 소개
- 6장 카드뉴스
- 20초 쇼츠

### 메인 카피

> # 이력서는 수천 개인데,  
> # 왜 후보자는 매번 처음부터 찾고 있을까요?

### 이야기

폴더에는 이력서가 잔뜩 쌓여 있습니다.

하지만 검색할 수 있는 것은 파일명뿐입니다.

> “자동차 부품회사 품질 경력.”  
> “영어가 가능하고 해외법인 경험이 있는 재무팀장.”  
> “반도체 공정 경험 10년 이상의 수도권 후보자.”

이런 조건으로는 찾을 수 없습니다.

필요한 후보자가 이미 회사 안에 있어도 어떤 파일인지 몰라 다시 외부에서 찾기 시작합니다.

엑스다임은 이력서 안의 경력, 학력, 직무와 전문 정보를 후보자 데이터로 정리합니다.

찾고 싶은 사람을 평소 말하듯 입력하면 실제 후보자 정보에서 조건에 맞는 사람을 찾습니다.

### 결론 카피

> **찾을 수 없는 인재풀은 보관함일 뿐입니다.**  
> **엑스다임은 쌓인 이력서를 다시 일하는 인재 자산으로 바꿉니다.**

### 6장 카드뉴스 구성

1. **우리 회사에는 이력서가 수천 개 있습니다.**
2. **그런데 찾을 수 있는 것은 파일명뿐입니다.**
3. **JD에 맞는 경력과 조건으로는 검색할 수 없습니다.**
4. **결국 이미 가진 후보자를 두고 다시 밖에서 찾습니다.**
5. **엑스다임은 이력서를 검색 가능한 후보자 데이터로 바꿉니다.**
6. **쌓인 이력서에서, 다시 일하는 인재풀로.**

## 4. 대표 스토리 C — JD에 맞는 후보, 누가 먼저 보입니까?

### 추천 용도

- 프로젝트 적합 후보 추천 광고
- 대표 기능 강조 카드뉴스
- 20~30초 쇼츠

### 메인 카피

> # 새 JD를 받을 때마다  
> # 기억나는 후보부터 떠올리고 있습니까?

### 이야기

새로운 프로젝트가 시작됩니다.

담당자는 기억나는 후보자를 떠올리고, 예전 메일과 엑셀을 뒤지고, 채용 사이트 검색을 다시 시작합니다.

하지만 사람의 기억은 회사가 확보한 모든 후보자를 비교할 수 없습니다.

엑스다임은 JD와 프로젝트 메모에서 필요한 조건을 정리합니다.

반드시 필요한 조건과 적합도를 높이는 조건을 나누고, 후보자의 실제 이력에서 근거를 확인해 검토할 후보군을 좁혀 보여줍니다.

AI가 최종 후보를 결정하지는 않습니다.

근거를 보고 누구를 실제 프로젝트에 올릴지는 컨설턴트가 선택합니다.

### 결론 카피

> **기억나는 후보가 아니라, 조건에 맞는 후보부터.**  
> **AI가 좁혀주고, 헤드헌터가 선택합니다.**

### 보조 카피 후보

- JD는 길어도, 검토할 후보는 선명하게.
- AI의 추천보다 중요한 것은 추천의 근거입니다.
- 후보자를 대신 고르는 AI가 아니라, 더 잘 고르게 돕는 AI.

## 5. 대표 스토리 D — 검색창이 헤드헌터의 말을 알아듣는다면

### 추천 용도

- 자연어·음성 검색 단독 광고
- 짧은 릴스와 쇼츠
- 랜딩 페이지 기능 카드

### 메인 카피

> # 검색 조건을 조립하지 말고,  
> # 찾는 사람을 설명하세요.

### 이야기

업종을 고르고, 직무를 고르고, 연차를 입력하고, 키워드를 바꿔가며 다시 검색합니다.

그래도 머릿속의 인재상과 검색 결과는 자꾸 어긋납니다.

엑스다임에서는 이렇게 말하면 됩니다.

> “소비재 업계에서 마케팅 조직을 이끌었고, 신규 브랜드 출시 경험이 있는 임원급 후보자를 찾아줘.”

텍스트로 입력해도 되고, 말로 검색해도 됩니다.

엑스다임이 헤드헌터의 표현을 실제 후보자 조건으로 바꾸어 찾습니다.

### 결론 카피

> **검색 문법은 엑스다임이 이해합니다.**  
> **헤드헌터는 원하는 사람만 설명하세요.**

### 초압축 카피

- 말하듯 찾는 인재 검색.
- 검색창이 헤드헌터의 말을 알아듣습니다.
- 조건을 누르지 말고, 인재를 설명하세요.

## 6. 대표 스토리 E — 이메일에 도착한 이력서가 일하기 시작한다

### 추천 용도

- 이력서 자동 수집·처리 기능 광고
- 데이터 자산화 메시지
- 6장 카드뉴스
- 20초 쇼츠

### 메인 카피

> # 오늘 이메일로 받은 이력서,  
> # 내일도 다시 찾을 수 있습니까?

### 이야기

후보자의 이력서가 이메일로 도착합니다.

바쁜 하루가 지나면 첨부파일은 받은편지함 아래로 밀려납니다.

누군가 파일을 내려받고, 폴더에 옮기고, 후보자 정보를 다시 입력해야 비로소 인재풀에 들어갑니다.

엑스다임은 회사 이메일에서 이력서 자료를 확인하고, 처리 흐름으로 가져옵니다.

이력서 속 후보자 정보를 구조화하고, 기존 후보자라면 현재 기록과 연결해 사람이 검토할 수 있게 준비합니다.

오늘 받은 이력서가 개인의 메일함에 머무르지 않고 회사가 다시 검색할 수 있는 데이터가 됩니다.

### 결론 카피

> **받은편지함에 머무는 이력서에서,**  
> **계속 활용되는 회사의 인재 자산으로.**

### 6장 카드뉴스 구성

1. **후보자의 새 이력서가 이메일로 도착했습니다.**
2. **다운로드하고, 폴더에 넣고, 다시 입력해야 합니다.**
3. **바쁘면 이력서는 받은편지함 아래로 사라집니다.**
4. **엑스다임은 이메일의 이력서 자료를 처리 흐름으로 가져옵니다.**
5. **후보자 데이터로 정리해 다시 검색하고 활용할 수 있게 합니다.**
6. **이메일에 들어온 이력서도 회사의 자산이 됩니다.**

## 7. 대표 스토리 F — 추천 이력서를 또 처음부터 만드시겠습니까?

### 추천 용도

- 추천 서류 생성 기능 광고
- 업무 시간 절약 메시지
- 전후 비교 카드뉴스

### 메인 카피

> # 후보자를 찾은 다음,  
> # 또 문서 작업이 시작됩니다.

### 이야기

적합한 후보자를 찾았습니다.

이제 원본 이력서를 열고, 고객사 양식을 열고, 경력과 학력을 다시 옮기고, 문장을 정리합니다.

후보자 한 명을 추천할 때마다 같은 작업이 반복됩니다.

엑스다임은 이미 정리된 후보자 정보와 정해진 양식을 이용해 제출용 추천 이력서를 준비합니다.

컨설턴트는 복사와 붙여넣기 대신 빠진 내용과 강조할 경력을 검토합니다.

### 결론 카피

> **문서를 옮겨 적는 시간은 줄이고,**  
> **후보자를 어떻게 소개할지에 집중하세요.**

### 보조 카피 후보

- 후보자 데이터는 한 번, 추천 서류에는 다시 활용.
- 반복 작성에서 최종 검토로.
- 추천 이력서는 엑스다임이 준비하고, 추천의 완성은 헤드헌터가 합니다.

## 8. 대표 스토리 G — 같은 채용공고를 몇 번 입력하십니까?

### 추천 용도

- 채용공고 생성·자동 게시 광고
- 업무 자동화 강조 카드뉴스
- 화면 시연형 쇼츠

### 메인 카피

> # JD는 하나인데,  
> # 채용공고는 왜 사이트마다 다시 써야 할까요?

### 이야기

프로젝트의 JD는 하나입니다.

하지만 채용 사이트마다 항목과 선택값, 공개 방식이 다릅니다.

같은 내용을 복사하고, 다시 다듬고, 사이트마다 하나씩 입력합니다.

엑스다임은 프로젝트 JD를 바탕으로 외부 공개용 공고문과 사이트별 게시 자료를 준비합니다.

지원하는 채용 사이트의 실제 등록 흐름에 맞춰 게시하고, 결과 확인과 마감까지 프로젝트에서 이어서 관리합니다.

### 결론 카피

> **한 번 준비한 JD를, 여러 채용 채널로.**  
> **반복 입력은 줄이고 후보자 발굴에 집중하세요.**

### 초압축 카피

- JD는 한 번, 채용 채널은 여러 곳.
- 사이트마다 반복하던 채용공고 등록을 하나의 흐름으로.
- 복사하고 붙이는 공고 업무에서, 확인하고 관리하는 공고 업무로.

## 9. 대표 스토리 H — 기능이 아니라 순환하는 인재 자산

### 추천 용도

- 브랜드 메시지
- 리플렛 마지막 면
- 랜딩 페이지 마무리
- 30초 브랜드 쇼츠

### 메인 카피

> # 엑스다임의 자동화는 일을 끝내고 사라지지 않습니다.  
> # 다음 일을 더 잘 시작하게 합니다.

### 이야기

이메일로 들어온 이력서는 후보자 데이터가 됩니다.

후보자 데이터는 자연어 검색과 프로젝트 추천에 활용됩니다.

선택된 후보자는 프로젝트 안에서 연락부터 면접과 클로징까지 이어집니다.

정리된 데이터는 추천 이력서를 만드는 데 다시 쓰입니다.

프로젝트의 JD는 채용공고와 사이트별 게시 업무로 이어집니다.

그리고 새로 들어온 이력서는 다시 회사의 인재풀을 더 풍부하게 만듭니다.

- 한 번의 업무가 다음 프로젝트의 자산이 됩니다.

**한 번의 업무가 다음 프로젝트의 자산이 되는 헤드헌팅 플랫폼, 엑스다임입니다.**

- 헤드헌터의 하루가 사람보다 복사와 붙여넣기에 쓰이고 있습니까?

### 해결을 압축한 문장

- 쌓인 이력서를 검색 가능한 후보자 자산으로.
- 기억나는 후보보다 조건에 맞는 후보부터.
- 조건을 조립하지 말고 찾는 사람을 설명하세요.
- 오늘 받은 이력서를 내일의 적합 후보로.
- 후보자 데이터는 한 번, 추천 서류에는 다시 활용.
- JD는 한 번, 채용 채널은 여러 곳.
- 담당자의 기억을 회사의 시스템으로.
- 따로 하던 자동화를 하나의 업무 흐름으로.

### 브랜드 슬로건 후보

1. **AI가 준비하고, 헤드헌터가 결정합니다.**
2. **JD 한 장에서 한 명의 입사까지.**
3. **헤드헌팅의 모든 맥락을, 하나의 흐름으로.**
4. **반복 업무는 엑스다임에게, 사람을 보는 시간은 헤드헌터에게.**
5. **오늘의 업무가 내일의 인재 자산이 됩니다.**
6. **흩어진 이력서는 하나의 인재풀로, 담당자의 기억은 회사의 자산으로.**
7. **이력서가 쌓일수록 더 잘 일하는 헤드헌팅 플랫폼.**
8. **사람을 찾는 일은 사람답게, 반복 업무는 AI답게.**
9. **데이터는 쌓이고, 판단은 빨라집니다.**
10. **복사하고 찾는 시간에서, 만나고 판단하는 시간으로.**

## 17. 우선 검토할 추천 조합

### 조합 1 — 가장 쉬운 설명

- 첫 질문: **이력서는 수천 개인데, 왜 후보자는 매번 다시 찾고 있을까요?**
- 핵심 해결: **쌓인 이력서를 검색 가능한 후보자 자산으로.**
- 전체 확장: **JD 한 장에서 한 명의 입사까지.**
- 브랜드 결론: **AI가 준비하고, 헤드헌터가 결정합니다.**

### 조합 2 — 자동화 강조

- 첫 질문: **JD는 하나인데, 왜 업무는 여러 번 반복해야 할까요?**
- 핵심 해결: **프로젝트, 후보 검색, 추천 이력서와 채용공고를 하나의 흐름으로.**
- 브랜드 결론: **따로 하던 자동화를 하나의 헤드헌팅 업무로.**

### 조합 3 — 대표·관리자 설득

- 첫 질문: **담당자가 바뀌면 후보자의 맥락도 사라집니까?**
- 핵심 해결: **개인의 이력서와 경험을 회사가 함께 쓰는 인재 자산으로.**
- 브랜드 결론: **담당자의 기억을 회사의 시스템으로.**

### 조합 4 — 헤드헌터 공감

- 첫 질문: **사람을 찾는 시간보다 정보를 옮기는 시간이 더 길지 않습니까?**
- 핵심 해결: **AI는 읽고, 찾고, 정리하고, 준비합니다.**
- 브랜드 결론: **반복 업무는 엑스다임에게, 사람을 보는 시간은 헤드헌터에게.**
