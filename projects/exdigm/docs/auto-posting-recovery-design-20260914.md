- **닫힘**: 내부 회사 분류와 사이트 업종 라벨이 다르다는 이유로 입력 생성을 중단하던 원래 경로. 실제 회사 조회 → 실제 선택지 → 선택 확인을 새 운영 공식 경로에서 통과했다.
- 다른 보정 분기는 원래 실패/변형 회귀 검사와 활성 다섯 사이트의 정상 실제 입력 경로로 확인했다. 모든 가능한 외부 사이트 장애가 없어졌다는 뜻은 아니다.
- PeopleNJob은 운영 설정상 비활성이다. 입력 보정 회귀 검사는 통과했지만 실제 로그인/게시 경로는 실행하지 않았다. 활성화 설정은 변경하지 않았다.
- JobKorea 마감 목록의 여러 페이지 탐색과 추가 실제 마감은 새로 검증하지 않았다. 이미 마감된 정확한 대상의 보정은 회귀 검사로 확인했다.
- 추가 실게시를 하지 않았으므로 이번 검증을 새 게시물 생성 증거로 사용하지 않는다. 원래 프로젝트의 앞선 게시 완료는 그대로 유지된다.

현재 요청의 구조 개선·운영 반영·활성 사이트 입력 확인은 완료했다. 후속 작업은 실제 새 장애나 비활성 사이트 활성화 요청이 있을 때 해당 증거를 기준으로 이어간다.
