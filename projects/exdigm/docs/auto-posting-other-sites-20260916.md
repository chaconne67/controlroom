## 실행과 판단의 경계

- 스크립트: 사이트별 순서, 화면 준비, 정확한 현재 선택지 수집, 허용된 선택 실행, 반영값 검사, 시간/호출 제한, 실패 증거.
- LLM: 원본 사실과 현재 선택지의 의미 대응. 이전 선택값은 참고이며, 사이트에 현재 존재하는 후보만 반환한다.
- 명백한 현재 선택은 그대로 실행하고, 현재 후보와 불일치하거나 의미 판단이 필요한 지점에서만 AI를 호출한다.
- 게시·결제·인증 우회·다른 단계 조작 권한은 AI에 주지 않는다. 필수 선택/반영 확인이 없으면 다음 단계로 진행하지 않는다.
- 기존 `autoposting → AutoPosting.main → common → sites/<site>.run` 경로만 사용한다. 새 런타임 모듈·실행기·의존성을 만들지 않는다.

## 리뷰 계약과 확인 기록

- 보호: 잡코리아 경로, 사이트 인증/공유 브라우저 수명, dry-only, 공고번호/마감 상태 보존, 익명화, 운영 데이터/실게시 권한.
