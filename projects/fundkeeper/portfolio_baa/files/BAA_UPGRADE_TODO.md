# BAA 전략 업그레이드 개발 투두 리스트

## 📋 프로젝트 개요
- **목표**: 기존 고정 종목 BAA 전략을 S&P 500 + NASDAQ 100 동적 선별 전략으로 업그레이드
- **총 작업 항목**: 28개
- **예상 개발 기간**: 19주

---

## 🎯 Phase 1: 데이터 인프라 구축 (1-6주)

### Phase 1.1: 데이터베이스 스키마 설계 (1-2주)
- [ ] **[HIGH]** DB 스키마 설계 및 구현 - sp500_stocks, nasdaq100_stocks, stock_metrics 테이블 생성
- [ ] **[HIGH]** 인덱스 최적화 및 데이터 무결성 제약조건 설정

### Phase 1.2: 데이터 수집 시스템 (3-4주)
- [ ] **[HIGH]** S&P 500 + NASDAQ 100 종목 리스트 API 연동
- [ ] **[HIGH]** 일일 가격 데이터 및 거래량/거래대금 데이터 수집 시스템 구현
- [ ] **[MEDIUM]** 에러 핸들링 및 재시도 로직 구현

### Phase 1.3: 자동화 시스템 (5-6주)
- [ ] **[HIGH]** 크론잡 스케줄러 설정 및 자동 업데이트 시스템 구현
- [ ] **[MEDIUM]** 데이터 검증 로직 및 업데이트 실패 시 알림 시스템 구현
- [ ] **[MEDIUM]** 로그 관리 시스템 구현

---

## 🧮 Phase 2: 종목 선별 알고리즘 개발 (7-11주)

### Phase 2.1: 평가 지표 계산 엔진 (7-8주)
- [ ] **[HIGH]** 평가 지표 계산 엔진 개발 (거래대금, 가격상승률, 변동성, 모멘텀)
- [ ] **[MEDIUM]** 지표 계산 성능 최적화 (벡터화 연산) 및 캐싱 시스템 구현

### Phase 2.2: 순위 알고리즘 (9-10주)
- [ ] **[HIGH]** 가중치 기반 종합 점수 계산 및 순위 알고리즘 구현
- [ ] **[MEDIUM]** A/B 테스트를 위한 다중 옵션 제공 및 백테스팅 검증 시스템

### Phase 2.3: 리밸런싱 로직 (11주)
- [ ] **[HIGH]** 리밸런싱 주기 설정 (주간/월간) 및 종목 교체 로직 구현
- [ ] **[MEDIUM]** 포트폴리오 연속성 보장 및 거래비용 최적화

---

## 🌐 Phase 3: 웹 인터페이스 통합 (12-15주)

### Phase 3.1: 웹 플랫폼 통합 (12주)
- [ ] **[HIGH]** 코코넛 웹 플랫폼에 새 전략 페이지 개발
- [ ] **[MEDIUM]** 기존 UI/UX 패턴 유지 및 반응형 디자인 적용
- [ ] **[MEDIUM]** 사용자 권한 관리 시스템 구현

### Phase 3.2: 검색 및 필터링 (13-14주)
- [ ] **[HIGH]** 종목명/티커 검색 API 개발
- [ ] **[MEDIUM]** 섹터별 필터링 및 지표별 정렬 컴포넌트 구현
- [ ] **[MEDIUM]** 페이지네이션 및 데이터 시각화 (차트) 구현

### Phase 3.3: 대시보드 개발 (15주)
- [ ] **[HIGH]** 대시보드 개발 - 선별된 종목 리스트 및 포트폴리오 성과 차트
- [ ] **[MEDIUM]** 리밸런싱 히스토리 및 위험 지표 모니터링 구현

---

## 📊 Phase 4: 백테스팅 및 성과 분석 (16-18주)

### Phase 4.1: 백테스팅 시스템 (16-17주)
- [ ] **[HIGH]** 과거 데이터 기반 백테스팅 시스템 확장
- [ ] **[HIGH]** 기존 BAA 전략과 성과 비교 및 리스크 지표 분석
- [ ] **[MEDIUM]** 최적 파라미터 탐색 시스템 구현

### Phase 4.2: 성과 분석 도구 (18주)
- [ ] **[MEDIUM]** 샤프 비율, MDD, 승률, 손익비, 변동성 분석 도구 개발
- [ ] **[MEDIUM]** 누적 수익률, 드로우다운, 월별/연도별 성과 히트맵 시각화
