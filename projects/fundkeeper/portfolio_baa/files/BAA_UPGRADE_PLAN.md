# BAA 전략 업그레이드 개발 계획서

## 프로젝트 개요

### 현재 BAA 전략
- **투자 대상**: 미리 정해진 특정 종목들 (고정)
- **전략**: 동적 모멘텀 자산배분
- **한계**: 투자 범위가 제한적

### 업그레이드 BAA 전략
- **투자 대상**: S&P 500 + NASDAQ 100 전체 종목
- **선별 기준**: 거래대금, 가격상승률 등 다중 지표
- **동적 선별**: 주기적으로 상위 N개 종목을 BAA 투자대상으로 선정
- **기존 전략 활용**: 선별된 종목들에 대해 기존 BAA 동적 자산배분 적용

## 개발 단계별 계획

### Phase 1: 데이터 인프라 구축

#### 1.1 데이터베이스 확장
- **목표**: 기존 프라이스 DB에 S&P 500 + NASDAQ 100 데이터 테이블 추가
- **작업 내용**:
  - 새 테이블 스키마 설계
    - `sp500_stocks` 테이블
    - `nasdaq100_stocks` 테이블
    - `stock_metrics` 테이블 (거래대금, 가격변동률 등)
  - 인덱스 최적화
  - 데이터 무결성 제약조건 설정

#### 1.2 데이터 수집 시스템
- **목표**: S&P 500 + NASDAQ 100 종목 데이터 자동 수집
- **작업 내용**:
  - 종목 리스트 API 연동
  - 일일 가격 데이터 수집
  - 거래량/거래대금 데이터 수집
  - 에러 핸들링 및 재시도 로직

#### 1.3 자동 업데이트 시스템
- **목표**: 매일 자동으로 데이터 업데이트
- **작업 내용**:
  - 크론잡 스케줄러 설정
  - 데이터 검증 로직
  - 업데이트 실패 시 알림 시스템
  - 로그 관리 시스템

### Phase 2: 종목 선별 알고리즘 개발

#### 2.1 평가 지표 계산 엔진
- **목표**: 다양한 평가 지표를 실시간으로 계산
- **평가 지표**:
  - 거래대금 (일평균, 주평균, 월평균)
  - 가격 상승률 (1일, 1주, 1개월, 3개월)
  - 변동성 지표
  - 모멘텀 지표
- **작업 내용**:
  - 지표 계산 함수 개발
  - 성능 최적화 (벡터화 연산)
  - 캐싱 시스템 구현

#### 2.2 종목 순위 시스템
- **목표**: 복합 지표 기반 종목 순위 매기기
- **작업 내용**:
  - 가중치 기반 종합 점수 계산
  - 순위 알고리즘 구현
  - A/B 테스트를 위한 다중 옵션 제공
  - 백테스팅 검증 시스템

#### 2.3 동적 선별 시스템
- **목표**: 주기적으로 투자대상 종목 업데이트
- **작업 내용**:
  - 리밸런싱 주기 설정 (주간/월간)
  - 종목 교체 로직
  - 포트폴리오 연속성 보장
  - 거래비용 최적화

### Phase 3: 웹 인터페이스 통합

#### 3.1 코코넛 웹 기능 통합
- **목표**: 기존 웹 플랫폼에 새 전략 통합
- **작업 내용**:
  - 새 전략 페이지 개발
  - 기존 UI/UX 패턴 유지
  - 반응형 디자인 적용
  - 사용자 권한 관리

#### 3.2 검색 및 필터링 기능
- **목표**: 사용자가 종목을 쉽게 탐색할 수 있는 인터페이스
- **기능 요구사항**:
  - 종목명/티커 검색
  - 섹터별 필터링
  - 지표별 정렬
  - 실시간 순위 표시
- **작업 내용**:
  - 검색 API 개발
  - 필터링 컴포넌트 구현
  - 페이지네이션
  - 데이터 시각화 (차트)

#### 3.3 대시보드 개발
- **목표**: 전략 성과 및 현황을 한눈에 볼 수 있는 대시보드
- **구성 요소**:
  - 현재 선별된 종목 리스트
  - 포트폴리오 성과 차트
  - 리밸런싱 히스토리
  - 위험 지표 모니터링
- **기술 스택**:
  - ApexChart.js (차트)
  - Alpine.js (인터랙션)
  - TailwindCSS (스타일링)

### Phase 4: 백테스팅 및 검증

#### 4.1 백테스팅 시스템 확장
- **목표**: 새 전략의 과거 성과 검증
- **작업 내용**:
  - 과거 데이터 기반 시뮬레이션
  - 기존 BAA 전략과 성과 비교
  - 리스크 지표 분석
  - 최적 파라미터 탐색

#### 4.2 성과 분석 도구
- **목표**: 전략의 강점과 약점 분석
- **분석 지표**:
  - 샤프 비율
  - 최대 낙폭 (MDD)
  - 승률 및 손익비
  - 변동성 분석

- **시각화**:
  - 누적 수익률 차트
  - 드로우다운 차트
  - 월별/연도별 성과 히트맵

## 기술 스택

### 백엔드
- **언어**: Python
- **프레임워크**: Django
- **데이터베이스**: MySQL (기존 프라이스 DB 확장)
- **데이터 처리**: Pandas, NumPy
- **스케줄링**: 크론잡

### 프론트엔드
- **스타일링**: TailwindCSS
- **차트**: ApexChart.js
- **인터랙션**: Alpine.js
- **템플릿**: Django Templates

### 인프라
- **컨테이너**: Docker
- **웹서버**: Nginx
- **모니터링**: 기존 시스템 활용

- 1주차: DB 스키마 설계 및 구현
- 2주차: 데이터 수집 시스템 개발
- 3주차: 자동 업데이트 시스템 구현
- 4주차: 테스트 및 최적화

- 1-2주차: 평가 지표 계산 엔진
- 3-4주차: 종목 순위 시스템
- 5-6주차: 동적 선별 시스템

### 3단계: 웹 통합
- 1-2주차: 코코넛 웹 통합

- 1-2주차: 백테스팅 시스템

### 5단계: 운영 준비
- 1주차: 모니터링 시스템
- 2주차: 최종 테스트 및 배포

**총 개발 기간: 19주 (약 5개월)**

### 기술적 위험
- **데이터 품질 이슈**: 다중 소스 검증, 이상치 탐지

## 체크포인트

### 기술적 지표
- 백테스팅 정확도 검증
- 기존 백테스트 속도 대비 20% 이상 초과되지 않게

### 비즈니스 지표
- 기존 BAA 대비 수익률, 샤프 지수 개선
- 사용자 만족도 점수
- 시스템 사용률 증가

## 개요

이 업그레이드는 기존 BAA 전략의 한계를 극복하고, 더 넓은 투자 유니버스에서 동적으로 상대 우위 종목을 선별하는 접근 방식입니다. 
체계적인 단계별 개발을 통해 안정적이고 효과적인 시스템을 구축할 수 있을 것입니다.
