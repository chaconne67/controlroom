모기지 모달 확인

실제 화면에는 표시하지 않는 시안 조작 도구입니다. 기업자금 화면은 기존 방식의 비교용이며, 업무 기능을 새로 설계하지 않습니다.

기존 목록 → 회사 모달 유지

기업자금·모기지 두 메뉴 묶음만 추가합니다. 기존 문자 발송, TM 상담, 통화 녹음 올리기, TM 진행 내역, 영업 화면의 배치·버튼·입력 방식·업무 순서는 유지합니다. 시안은 기존 문자 발송 목록과 회사 모달의 구조를 사용하며, 다른 업무 화면은 새로 그리지 않습니다.

모기지 모달의 처음 상태

기존 회사 기본정보 아래에 재무정보, 부동산 정보 순서로 배치합니다. 재무정보는 접힘, 부동산 정보는 펼침으로 시작합니다. 각각 클릭해서 따로 접고 펼칠 수 있고, 둘 다 열거나 둘 다 접을 수 있습니다. 모달을 닫았다 다시 열면 같은 초기 상태로 시작합니다.

모바일·긴 내용

기존 최대 폭 4xl, 화면 높이 85% 이내의 모달 틀과 내부 세로 스크롤을 유지합니다. 제목과 닫기 버튼은 내용 스크롤 밖에 있습니다. 작은 화면에서도 모달은 화면 안에 있고, 넓은 표만 표 안에서 가로로 스크롤합니다.

구현 메모 · 실제 화면에는 표시하지 않음

재사용 기준은 funding/_admin_rows.html, _admin_items.html, _progress_modal.html, _company_panel.html입니다. 운영의 .darkhead-table, .btn, .input, .select 스타일시트를 직접 참조합니다. 기업자금의 기존 include와 표시 방식은 변경하지 않고 모기지에만 두 정보 영역을 적용합니다. TM 상담·진행 내역에 이미 있는 상담 기록·액션 영역도 그대로 둡니다.

모기지 금융 사실은 같은 회사 정본을 읽습니다. 재무가 없으면 ‘재무 데이터가 없습니다’로 표시하며 부동산 열람을 막지 않습니다. 부동산은 물건별 소유·취득·거래 범위·권리·공동담보·신탁·원문을 표시합니다. 채권최고액과 실제 잔액을 구분하고, 공동담보와 전체 계약금액을 물건별로 더하지 않습니다. 검토 중 수치를 확정해 보여주지 않습니다.

결정 사항

주인님 지시로 기존 UI·UX 유지, 별도 상세 페이지 제거, 같은 모달 안의 두 토글, 부동산 기본 펼침을 확정했습니다. 새 대상 회사 메뉴·연락처 확인 TM 분기·새 업무 화면 제안은 철회합니다. 기존 권한·문자 대상 조건·영업 전달 절차를 유지합니다.

구현 단계

  1. 기존 메뉴 링크를 기업자금으로 묶고 같은 메뉴 구성의 모기지 업무 범위를 연결합니다.
  2. 기존 회사 모달과 재무 표시를 재사용하며 모기지에만 부동산 영역을 추가합니다.
  3. 기본 펼침·접힘, 내부 스크롤, 재무 유무, 원문 권한과 업무별 기록 분리를 기존 실제 경로에서 검증합니다.
