# crema 앱 아이콘

| 파일 | 상태 | 설명 |
|---|---|---|
| `crema-c-bubble.svg` | **채택** | 말풍선 속 에스프레소 위 크레마 층. 이름(크레마)과 앱 역할(대화)을 함께 보여 줌 |
| `crema-a-cup.svg` | 보관 | 위에서 본 잔 속 크레마 소용돌이. 이름 뜻이 가장 바로 전달됨 |
| `crema-concepts.png` | 참고 | 3종 비교표(256/64/32px). B는 파일을 보관하지 않음 |

- 색: 에스프레소 #3B2418→#1A0F0A, 크레마 #F6D19A→#D99A55→#9A5527, 크림 #F7EEE2(A)·#F5EBDD(C 바탕).
- 앱 적용: `npx tauri icon crema-c-bubble.svg -o <출력 폴더>`로 만든 파일을 `src-tauri/icons/`에 덮어쓴다(파일 이름이 기존과 같아 설정 변경 없음). Android·iOS 폴더는 쓰지 않는다.
