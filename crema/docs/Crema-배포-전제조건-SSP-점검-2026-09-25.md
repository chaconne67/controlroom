## 최종 경로(SSP) 정의

배포된 Crema의 성공 경로는 하나다.

1. GitHub 최신 릴리스에서 `Crema-setup-x64.exe`를 받는다
2. 사용자가 직접 실행해 설치한다(격리되지 않은 사용자 계정)
3. Hermes가 없으면 설치 과정에서 함께 설치된다
4. 바탕화면·시작 메뉴 아이콘으로 Crema를 실행한다
5. "이 PC" 연결 → Provider 로그인 → 첫 질문에 실제 답변이 온다
6. 재부팅 뒤 다시 실행해도 연결과 대화 기록이 유지된다

지금까지의 검증은 2~6을 **개발 PC의 Claude 격리 환경**에서 했고, Hermes가 없는 PC에서는 한 번도 하지 않았다.
