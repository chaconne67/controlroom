| 기능 | 내용 | AI 비용 | 현재 |

## 결정

- 연결 대상: 핵심 Gemini API·Groq·OpenRouter, 보조 Mistral·Vercel AI Gateway·GitHub Copilot SDK(OAuth).
- 제외: 카드 필요(Cerebras, 클라우드 신규 크레딧), 개발도구 로그인(Antigravity·Cursor·Kiro·Windsurf·Codex), 웹 무료 계정 자동화, 종료된 GitHub Models.
- 가입·약관 동의·클릭·입력은 사용자가 직접 합니다. 자동 가입·자동 클릭·CAPTCHA 처리는 하지 않습니다.
- Jev·안내 모델 키는 main 서버 비밀값에만 둡니다. 사용자 제공처 키는 사용자 PC에만 둡니다.
- 민감 정보로 판정된 요청은 입력을 학습에 쓰는 무료 등급(Gemini 무료)으로 보내지 않습니다.

## 확인한 사실

- 엔진 `/v1/runs`는 요청 `model`에 `provider::model`을 받아 턴별 모델 지정이 됩니다. 세션 모델 고정과 충돌 검사가 있으므로 자동 모드 세션은 고정하지 않습니다.
- 엔진에 Gemini·OpenRouter·Copilot·Hugging Face·Vercel AI Gateway 연결 모듈이 있습니다. Groq·Mistral은 OpenAI 호환 사용자 지정 제공처로 붙입니다.
- Jev 시험(2026-09-26, jev-1.13.0): 한국어 요청 12건 중 난이도 10건 일치, 지연 198~618ms, 요청당 입력 약 591토큰(100만 건 약 25달러). 민감 정보·실시간 정보 필요를 정확히 잡았습니다.
- GitHub Models는 2026-07-30 종료, Gemini CLI 개인 무료 로그인은 2026-06-18 Antigravity CLI로 대체됐습니다.
