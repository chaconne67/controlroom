# CRETOP 스마트검색 조건

이 문서는 실제 화면에서 확인한 이름과 값 매핑입니다. 사이트가 바뀔 수 있으므로 조작 전 현재 화면과 대조합니다.

## 진입 화면

- 상단 메뉴: `기업`
- 화면 이름: `스마트검색`
- 상세 조건 버튼: `상세조건 검색`
- 상세 조건 창: `스마트검색 조건 전체보기`
- 탭: `상세정보`, `재무정보`, `업종`
- 닫기 버튼 이름: `팝업닫기`

## 상세정보 입력

| 조건 | 화면 요소 | 확인된 식별값 |
| --- | --- | --- |
| 키워드 | 입력 | `#srchKeyWord` |
| 상품명 | 입력 | `#maPdCtt` |
| 기업상태 | 체크박스 | 정상 `01`, 휴업 `03`, 폐업 `04` |
| 기업규모 | 체크박스 | 대기업 `01`, 중견기업 `05`, 보호대상중견기업 `07`, 한시성중소기업 `04`, 중기업 `02`, 소기업 `03`, 소상공인 `06`, 판단제외 `08` |
| 기업유형 | 체크박스 | 유가증권시장 `1`, 코스닥시장 `2`, 코넥스 `7`, 등록법인 `3`, 외감 `4`, 일반법인 `5`, 개인사업자 `6` |
| 지역 | 단일 선택 | 서울, 부산, 대구, 인천, 광주, 대전, 울산, 세종, 경기, 충북, 충남, 전남, 경북, 경남, 제주, 강원, 전북 |

식별값으로 직접 조작하기 전에 화면의 라벨과 현재 선택 상태가 함께 일치하는지 확인합니다.
