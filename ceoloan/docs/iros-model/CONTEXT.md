# 부동산 등기 모델 설계 용어

IROS 등기 원문으로 부동산과 그 권리 이력을 분석할 때 사용하는 용어다. 2026-09-17 실제 건물 등기 표본에서 구분한 의미를 담으며, 운영 적용 전 저장 모델 설계에 사용한다.

## 언어

**등기 대상 부동산**:
등기 고유번호로 구별되는 토지·건물·집합건물의 전유부분이다. 같은 주소의 토지와 건물은 서로 다른 등기 대상일 수 있다.
_피할 표현_: 회사 부동산, 주소와 동일한 자산

**사업장 주소 연결**:
회사의 사업장 주소로 검색해 특정 부동산을 찾았다는 관계다. 소유자가 회사와 동일하다는 확인을 포함하지 않는다.
_피할 표현_: 회사 소유 부동산, 담보 제공 확정

**등기 물건의 연결관계**:
토지·건물·전유부분 사이에서 원문으로 확인된 연결이다. 한 건물에 여러 토지가 연결될 수 있으며, 연결 자체는 소유자나 담보권이 같다는 뜻이 아니다.
_피할 표현_: 같은 주소이면 같은 물건, 연결된 모든 물건은 동일 소유

**토지 분할**:
한 필지에서 일부 면적이 다른 지번의 필지로 나뉘고 원래 필지의 면적이 바뀐 사건이다. 분할되어 나간 필지의 지번이 확인되어도 그 필지의 등기 고유번호까지 확인된 것은 아니다.
_피할 표현_: 면적만 덮어쓰기, 공유물분할과 무조건 같은 사건

**대지권**:
구분건물의 전유부분과 연결되어 등기되는 대지사용권이다. 목적 토지마다 기록된 종류와 비율을 구분하며 전유면적이나 전유부분의 소유 지분과 같다고 가정하지 않는다.
_피할 표현_: 건물 소유 지분, 목적 토지와 연결하지 않은 하나의 토지 비율

**등기 문서**:
특정 열람 또는 발급 시점에 확인한 등기기록을 담은 원문이다. 다른 시점의 문서는 같은 부동산의 다른 관측이다.
_피할 표현_: 항상 최신인 등기, 전체 과거를 보장하는 자료

**등기 항목**:
표제부·갑구·을구에서 표시번호나 순위번호로 구별되는 기록이다. 부기 항목은 기존 기록의 일부 표시나 권리를 바꿀 수 있다.
_피할 표현_: 숫자로 시작하는 모든 문장, 독립 대출 한 건

**소유권 취득**:
등기에 나타난 원인에 따라 특정 당사자가 부동산의 지분을 받은 기록이다. 매매·증여·보존·상속·신탁 등의 원인을 구분한다.
_피할 표현_: 모든 소유권이전을 매수라고 부르기

**매매 거래**:
매매 원인과 계약 또는 매매목록으로 연결되는 자산·지분·매도인·매수인의 거래다. 한 거래가 여러 부동산이나 여러 취득 항목에 나타날 수 있다.
_피할 표현_: 등기 항목 하나와 반드시 같은 거래

**거래가액**:
등기 본문이나 매매목록에 기재된 거래 금액이다. 개별 부동산·지분 또는 거래 전체 중 어떤 범위의 값인지 함께 구별한다.
_피할 표현_: 자산별로 반복 합산하는 전체 계약가격, 확인하지 않은 시세

**등기명의자**:
원문에서 소유자나 공유자로 기재된 당사자다. 신탁의 수탁자와 수익자는 다른 역할이다.
_피할 표현_: 사업장 운영자, 채무자와 무조건 동일한 사람

**현재 남은 지분**:
특정 등기 문서 시점에 이전·변경 관계를 반영하고 해당 당사자에게 남아 있는 소유권 지분이다. 여러 시기의 취득 지분이 함께 남아 있을 수 있다.
_피할 표현_: 마지막 취득 항목에 적힌 지분만

**근저당권**:
채권최고액과 채무자·근저당권자 등을 기재한 담보권이다. 실제 대출 계약이나 잔액과 구별한다.
_피할 표현_: 대출 한 건, 실제 부채

**채권최고액**:
근저당 등기에 기재된 담보의 최고 금액이다. 원금·미상환 잔액·실제 실행금액과 동일한 값이 아니다.
_피할 표현_: 대출 잔액, 실제 원금

**실제 대출 잔액**:
특정 기준일에 금융기관 등 확인 가능한 자료에서 증명한 미상환 금액이다. 등기된 최고액만으로 알 수 없다.
_피할 표현_: 최고액에서 일정 비율로 역산한 사실값

**채무자**:
등기에 해당 담보권의 채무자로 표시된 당사자다. 부동산 소유자나 사업장 회사와 다를 수 있다.
_피할 표현_: 소유자와 항상 동일한 사람

**근저당권자**:
등기에 해당 근저당권의 권리자로 표시된 당사자다. 은행·협동조합·개인·국가 등이 포함될 수 있다.
_피할 표현_: 반드시 은행

**공동담보**:
동일 담보권과 명시적으로 연결된 여러 부동산이다. 구성원 일부의 담보 소멸과 권리 전체의 말소를 구분한다.
_피할 표현_: 은행·금액·날짜가 같은 모든 권리

**담보물 추가**:
기존 담보권에 다른 부동산이 담보물로 편입된 사건이다. 편입된 물건의 등기에 설정 기록이 생겨도 새 대출이 실행되었다는 뜻은 아니다.
_피할 표현_: 추가설정일을 대출 시작일로 사용하기

**목록의 반복 인쇄**:
같은 매매목록 등이 여러 요청 항목에 따라 한 원문에 반복하여 나타난 상태다. 인쇄된 사본 수와 거래 수·거래가격 관측 수를 구분한다.
_피할 표현_: 인쇄된 각 목록을 독립 거래로 합산하기

**등기상 말소**:
원문의 말소 항목과 말소 표시로 확인되는 기록의 삭제 또는 변경 상태다. 일부 이름·주소가 지워진 것과 권리 전체가 말소된 것은 다르다.
_피할 표현_: 말소선이 하나라도 있는 행 전체 삭제

**등기원인일**:
등기원인으로 기재된 계약·증여·해지 등의 날짜다. 접수일·관측일과 구분한다.
_피할 표현_: 무조건 대출 실행일, 무조건 소유권 효력일

**등기 접수일**:
해당 기록의 신청이 접수됐다고 기재된 날짜다. 같은 날의 사건은 접수번호도 함께 구별한다.
_피할 표현_: 계약일과 같은 날짜라고 가정하기

**열람시점 상태**:
특정 문서를 열람한 시점에 원문과 변경 관계로 확인한 등기 상태다. 실제 금융 잔액이나 모든 권리의 법률상 효력 판정과 구분한다.
_피할 표현_: 실시간 잔액, 확정 법률 의견

**신탁원부**:
신탁등기와 연결된 계약·당사자·수익권·신탁재산·기간·조건을 담는 기록이다. 원부의 존재만으로 열람시점에 신탁이 존속한다고 판단하지 않는다.
_피할 표현_: 신탁원부가 있으면 현재 신탁 중, 일반 근저당과 동일한 권리

**우선수익자**:
신탁재산에서 정해진 순위와 조건으로 우선 변제받을 수익권의 당사자다. 수탁자·등기명의자·채무자·잔여수익자와 역할을 구분한다.
_피할 표현_: 수탁자, 모든 경우의 근저당권자

**우선수익 한도**:
신탁 계약이나 수익권증서에서 정한 수익권의 금액 범위다. 실제 실행된 대출금이나 현재 잔액을 증명하는 값은 아니다.
_피할 표현_: 현재 대출 잔액, 등기된 근저당 채권최고액

**신탁의 조건부 기간**:
원문에 정한 기본 기간과 자동 연장·조기 종료 조건을 함께 본 기간이다. 기본 기간을 계산한 날짜만으로 실제 종료를 확정하지 않는다.
_피할 표현_: 무조건 대출 만기, 연장 조건을 무시한 신탁 종료일

**계약 특약의 우선 적용**:
동일 계약에서 특약이 기본 조항을 바꾸거나 적용을 제외한다고 정한 관계다. 기본 조항과 특약을 서로 독립된 현재 조건으로 읽지 않는다.
_피할 표현_: 모든 조항을 같은 조건으로 단순 합산

**원문 값의 가림과 공란**:
원문이 개인정보 등을 가린 상태와 서식 칸을 비워 둔 상태다. 읽기 어려운 글자나 추출에 실패한 값과 구분한다.
_피할 표현_: 가린 번호를 추정하기, 공란을 추출 실패로 처리하기

**가등기와 본등기의 연결**:
같은 순위번호 아래 가등기와 본등기가 기록되어도 신청 원인·접수·당사자가 다른 사건이다. 가등기권자의 권리 양도와 부동산 소유권의 최종 취득을 구분한다.
_피할 표현_: 가등기를 즉시 소유권 취득으로 계산, 순위번호 하나를 사건 하나로 고정

**대지권의 담보 편입**:
전유부분에 설정된 담보의 목적에 대지권을 추가하는 기록이다. 설정행이 추가되어도 원문이 기존 담보와 연결하면 동일 담보관계를 보존한다.
_피할 표현_: 같은 물건의 각 설정행 최고액을 무조건 별도 대출로 합산

**경매 개시와 경매 매각**:
경매를 시작하는 기록과 이후 매각으로 소유권을 취득하는 기록이다. 개시 날짜를 소유권 취득 날짜나 매각대금 지급일로 사용하지 않는다.
_피할 표현_: 경매 관련 날짜를 모두 구매 날짜로 통합

**강제경매와 임의경매의 등기 관측**:
원문에 기재된 강제경매개시결정과 임의경매개시결정을 서로 다른 사건 종류로 저장한다. 법원·사건번호·개시 접수·취하 또는 말소 관계를 보존하며, 사건의 진행 상태나 최종 매각 결과는 등기 원문 밖에서 추정하지 않는다.
_피할 표현_: 모두 같은 경매 사건, 경매 개시를 완료된 소유권 취득으로 계산

**근저당권부채권의 가처분**:
근저당권에 딸린 채권을 대상으로 원문에 기록된 가처분이다. 부동산 소유권 자체의 가처분과 대상을 구분하고 근저당 설정 항목·해당 가처분·그 말소를 각각 연결한다.
_피할 표현_: 근저당의 채무자 변경, 부동산 전체의 가처분으로 무조건 통합

**분할 전사와 등기기록 이기**:
필지 분할에 따라 담보 기록을 옮기는 전사와 등기기록 과다 등으로 기록을 새 등기기록에 옮기는 이기를 구분한다. 원래 설정 접수·이전 표시번호·옮긴 접수 또는 이기일을 보존한다. 이기는 새 취득이나 새 대출이 아니며 현재 문서가 이전 전체 이력을 담는다고 가정하지 않는다.
_피할 표현_: 옮겨 적은 날짜를 최초 설정일로 덮어쓰기, 이기로 지워진 행을 담보 해지로 처리

**등기에 명시된 담보 대상 범위**:
통물건·특정 공유 지분·건물 부분·대지권·권리부채권 등 원문이 명시한 담보 또는 제한의 대상이다. 나중에 대지권이 등기되었다는 이유로 건물만 담보하는 근저당에 대지권을 자동 편입하지 않는다.
_피할 표현_: 같은 등기 문서에 있으면 모든 부분이 같은 담보 범위

**공동 1순위 우선수익자**:
한 신탁계약에서 같은1순위로 표시된 여러 법인이다. 기관별 수익한도·취급점·피담보채권 약정과 공동순위를 각각 보존하고, 계약이 정한 동순위 배분 조건을 별도로 기록한다. 수탁은행이 이들 법인의 채권을 모두 직접 가진다고 추정하지 않는다.
_피할 표현_: 우선수익자 한 곳으로 합치기, 순위1·2·3을 임의로 부여하기

**등기기록의 보존 범위**:
현재 열람 문서가 담고 있는 이력의 범위다. 등기기록 과다로 옮겨진 일부 기록만 있으면 전 생애의 취득·대출 이력으로 확대하지 않는다.
_피할 표현_: 현재 문서의 취득2건을 물건의 평생 취득2건으로 확정하기
