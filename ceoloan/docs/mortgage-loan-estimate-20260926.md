## 1. 승인된 요구 (2026-09-26, 추천안 전체 승인)

- 모기지 대상(모텔·여관 등 숙박업)은 문자를 보내지 않는다. 회사 대표번호로 TM이 직접 전화한다.
- 핵심 정보는 **등기부 기준 대출 가능 금액**이다. 기업자금 화면(금액 → 자격 판정 → 재무)과 같은 배치·디자인 시스템을 쓴다.
- 산식은 `mortgage/AI숙박업경영진단결과서_대출산정_조건값.xls`(조정실 `projects/ceoloan/mortgage`)의 「담보비율및 대출가능금액」·「조건값」 시트를 따른다.
- 결정 5가지: 현재 살아 있는 근저당 전부 합산(공동담보는 근저당권자·채권최고액이 같으면 한 번), 검토 전 원문 자동 판독 값을 「추정」으로 표시, 지역은 부동산 소재지 기준, 모기지 문자는 메뉴에서만 제거(코드 보존), 계수는 코드 고정·지역 비율만 화면에서 수정.

## 2. 산식과 판정

- A 추정 원금 = 채권최고액 ÷ 1.2, C 추정 감정가 = A × 2.05, D = C × 지역 비율, **E = D − A**. 표시는 E ~ E × 1.2를 백만원 아래 버림으로 「5,900만원~7,100만원」처럼 말한다. 엑셀 예시(28.47억, 강원 군지역 50%) → E 59,312,500원을 테스트로 고정했다. 엑셀 예시 칸의 「~70백만」은 사람이 적은 값이고 산식 그대로는 71백만이다.
- 근저당마다 그 물건 소재지 비율을 적용한다. 구 이름이 표에 있으면 그 값, 없으면 같은 시도의 시지역·군지역 값. 표에 없는 지역·근저당 없음·원문 없음은 금액을 만들지 않고 이유를 보인다.
- 제외: 을구 접수 1년 이내 설정·채권최고액 변경 등기, CRETOP 대출제한 3종(3개년 연속 결손, 최근 결산 자본총계 < 자본금, 차입금 > 매출 + 2년 연속 이자보상배수 < 1), 추가 여력 100만원 미만, 기숙사·고시원(I55901). 경영분쟁·업무중단·부도는 원천 자료가 없어 판정 보류로만 표시한다.
- 영업 준비 단계: 전화 가능(금액+번호) / 금액 확인 필요 / 등기 열람 필요(CRETOP 상세·번호는 있고 등기 없음) / 기본정보 수집 필요 / 제외.

## 3. 원문 해석에서 확인한 규칙 (실제 원문 90개 대조)

- PDF 글자라 등기 목적이 줄마다 끊긴다(「1번근저당권설정등 / 기말소」, 「9번근저당권설정, / 10번근저당권설정 / 등기말소」). 공백을 지운 전체 글자에서 말소 대상 순위를 읽는다.
- 한 순위 안의 (1)·(2) 근저당, 「갑구2번○○지분 전부근저당권설정」 지분 근저당을 각각 센다. 전세권 위 근저당(「7번전세권근저당권」)은 물건 담보가 아니므로 제외한다.
- 부기(N-M)의 「말소」(공동담보 일부 소멸 등)는 말소 등기가 아니다. 이 오판으로 61.9억 근저당이 빠지던 사례를 고쳤다(해석기 v3).
- 결과: 문서 99개 중 원문 텍스트 있음 90, 금액 산정 67개 회사, 현재 근저당 없음 23개 회사, 원문 없음 7개 회사(개발 DB 기준).
