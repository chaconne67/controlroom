## 포지셔닝 원칙

| 금지 | 대신 |
|------|------|
| "AI가 씁니다" | 언급 없음 — 내부 노하우 |
| "직접 써보세요" | "저희가 해드립니다" |
| 기능 나열 | 서비스 결과물 + 전문성 강조 |
| 도구(tool) 프레임 | 관리 서비스(managed service) 프레임 |

**핵심 메시지:** 10년 이상 경력의 연구소 관리 전문가가, 연구 주제 선정부터 세액공제 증빙까지, 매월 빠짐없이 관리해드립니다.

## 카피 원칙 (v2)

1. **"AI"는 없다** — 내부 방법론, 외부 노출 금지
2. **"직접"이 아니라 "대신"** — 우리가 해드린다는 프레임
3. **서류 더미 이미지가 무기** — "30여건"으로 양감 전달, 숫자 정확도보다 압도감
4. **공포 → 신뢰 순서** — 문제 제시 후 전문성으로 안심
5. **대표가 읽는다** — 실무 아님, 의사결정 언어
6. **CTA는 "신청"** — 상담 신청, 소개서 받기 (행동장벽 낮춤)
