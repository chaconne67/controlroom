# CRETOP 본문 마커 탭 선택 통합 계획

## 목표

탭 제목과 무관하게 각 Chrome 탭의 본문 텍스트를 확인해 CRETOP 탭을 선택한다. 선택 뒤에는 기존 프리플라이트와 만료·재로그인·팝업 처리가 화면 모드에 따라 그대로 실행된다.

## 원인

- 현재 `select_cretop_tab()`은 제목의 `(online<숫자>)`만 CRETOP 탭으로 인정한다.
- 페이지 만료 뒤 실제 제목은 `CRETOP - Chrome`으로 바뀌었다.
- 본문에는 `페이지가 만료되었습니다`, `Result Code: -1405`가 있었지만 제목 단계에서 중단되어 만료 복구가 실행되지 않았다.

## 변경 계약

1. CRETOP 탭 판정에서 제목 정규식을 제거한다.
2. Chrome 창과 탭을 순서대로 순회하며 현재 탭의 본문을 복사한다.
3. 기존 마커를 한 곳에서 다음 모드로 분류한다.
   - `expired`: 페이지 만료·`Result Code: -1405`·`[8004]`
   - `login_recovery`: 재로그인·시간연장·동시접속·로그인 확인
   - `service_popup`: KODATA 서비스 팝업
   - `ready`: 로그인 완료와 CRETOP 공통 레이아웃
   - `landing`: 랜딩페이지
   - `smart_search`: 스마트 검색
   - `search_result`: 기업 검색 결과
   - `detail`: 기업 상세페이지
4. 위 모드 중 하나가 확인된 첫 탭을 CRETOP 탭으로 선택한다.
5. 선택 결과에는 모드와 일치한 마커를 기록하되 제목은 진단 정보로만 남긴다.
6. 어떤 모드도 확인되지 않으면 탭을 임의 선택하지 않고 실패한다.
7. 선택된 탭의 상태 처리는 기존 `_ensure_ready_fast()`와 `collect_batch_fast()`가 맡는다.

## SSP 병합 위치

- 현재 경로: `collect_batch_fast()` → `_ensure_ready_fast()` → `select_cretop_tab()` → 상태별 프리플라이트·복구
- 병합 위치: 기존 `select_cretop_tab()`
- 대체 대상: 제목 정규식 기반 CRETOP 판정과 제목 우선 Chrome 창 선택
- 유지 대상: 탭 순회, 기존 Chrome 세션, 좌표, 페이지 만료 복구, 재로그인 복구, 회사 검색·상세 수집

## 검증

1. 제목이 `CRETOP - Chrome`인 만료 화면을 `expired`로 선택한다.
2. `(online<숫자>)` 제목이어도 본문이 CRETOP이 아니면 선택하지 않는다.
3. 정상·랜딩·스마트 검색·검색 결과·상세·재로그인·서비스 팝업을 각 모드로 선택한다.
4. 여러 Chrome 창과 탭에서 비-CRETOP 본문을 건너뛰고 CRETOP 본문 탭을 선택한다.
5. 기존 만료 감지·로그인 복구·상세 수집 계약 테스트를 함께 통과한다.
6. 원격 현재 만료 화면에서 공식 SSP를 실행해 탭 선택 → 만료 복구 → 첫 회사 검색이 이어지는지 확인한다.
7. 성공하면 동일한 공식 경로로 나머지 미처리 회사를 실행한다.

오류 코드는 문구용 공백·기호 정규화를 적용하지 않고 원문 문맥으로 확인한다. 정상 주소의 `1405호`나 재무 값 `-1405`는 만료로 판정하지 않는다.

## 제외

- URL, 탭 제목, 북마크, 새 탭, 새 Chrome을 CRETOP 판정 근거로 사용하지 않는다.
- Chrome 창이나 탭을 닫지 않는다.
- 기존 예외 처리에 별도 우회 경로를 추가하지 않는다.
- 회사명·사업자번호·한 번의 화면 값은 영구 규칙에 넣지 않는다.
