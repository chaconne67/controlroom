# CRETOP 클릭·마커 재시도 설계

## 목적

CRETOP 최종 경로의 모든 논리적 `클릭 → 마커 확인` 단계가 일시적인 클릭 누락이나 화면 전환 지연을 같은 방식으로 복구하게 한다.

- 마커 확인 간격: 1초
- 한 번의 클릭 뒤 마커 확인 제한시간: 10초
- 재시도: 최초 클릭 실패 뒤 최대 3회
- 총 클릭 횟수: 최대 4회
- 마지막 확인 실패: 현재 회사를 실패 처리하고 전체 배치를 즉시 중단

좌표, 마커, 화면 순서, DB 저장 계약은 바꾸지 않는다.

## 현재 문제

현재 섹션 수집은 이동 좌표를 한 번 클릭한 뒤 본문 복사와 마커 확인만 반복한다. 최초 클릭이 화면 전환을 만들지 못하면 10초 동안 이전 화면을 계속 읽고 실패한다. 확인을 반복하지만 전환을 생산하는 클릭은 다시 실행하지 않는다.

이 동작은 섹션 이동뿐 아니라 로그인 복구, 홈 이동, 검색, 상세 진입 등 여러 위치에 각각 구현되어 있다. 각 위치에 별도 반복문을 추가하면 재시도 횟수와 오류 처리 규칙이 달라질 위험이 있다.

## 선택한 구조

`scripts/cretop_agent.py` 안의 기존 클릭과 마커 확인을 하나의 공통 재시도 계약으로 묶는다. 새 실행 파일이나 별도 runner는 만들지 않는다.

공통 단계는 다음 순서를 수행한다.

1. 기존 클릭 또는 기존 클릭 묶음을 한 번 실행한다.
2. 기존 마커 확인기를 1초 간격, 최대 10초 조건으로 실행한다.
3. 목표 마커가 확인되면 클릭 결과, 마커 결과, 시도 횟수를 반환한다.
4. 마커 시간초과이면 같은 클릭 동작을 다시 실행한다.
5. 재시도 3회까지 실패하면 마커 시간초과 예외를 다시 발생시킨다.
6. 호출자는 기존 실패 흐름대로 현재 회사를 실패 처리하고 배치를 중단한다.

마커 시간초과와 다른 오류를 구분한다. 페이지 만료, 클립보드 오류, 알 수 없는 레이아웃, 보안·로그인 오류는 재클릭하지 않고 기존 복구 또는 즉시 실패 흐름으로 전달한다.

## 적용 범위

### 적용하는 논리적 클릭

- KODATA 서비스 팝업의 `1주일 동안 열지않음` 1회 클릭, 닫기 클릭과 팝업 문구 사라짐
- 시간연장 확인 클릭과 로그인 완료 마커
- 재로그인·동시접속 복구의 각 기존 클릭과 다음 단계 마커
- 로그인 확인 팝업 클릭과 로그인 완료 마커
- 상세 화면의 브리핑 클릭과 브리핑 마커
- CRETOP 로고 클릭과 홈 마커
- 검색 버튼 클릭과 검색 결과 상태
- 검색 결과 회사 클릭과 상세 기본 화면 마커
- 일반, 현황, 기술인증, 재무, 재무진단, 재무분석, 신용 클릭과 각 섹션 마커

재로그인처럼 클릭이 여러 단계인 흐름은 전체 흐름을 처음부터 반복하지 않는다. 각 클릭과 그 클릭이 생산해야 하는 바로 다음 마커만 하나의 재시도 단위로 둔다.

### 적용하지 않는 클릭

- 검색어 입력창에 초점을 주는 클릭
- 본문을 선택하고 `Ctrl+A/C`로 복사하기 위한 클릭
- 화면 전환 마커를 생산하지 않는 포커스·관찰 동작
- 만료 복구의 하드 리프레시

## 마커 판정

기존 마커와 판정 의미를 그대로 사용한다.

- 마커 존재: 로그인 완료, 홈, 브리핑, 상세 기본 화면, 각 상세 섹션
- 마커 부재: 서비스 팝업 닫힘
- 종결 상태 분류: 검색 결과의 `present`, `absent`, `ambiguous`

검색 결과의 `absent`와 `ambiguous`는 검색 클릭이 정상적으로 결과를 생산한 상태다. 재시도 대상으로 보지 않는다.

상세 하위 화면은 기존 계약대로 이전 복사문과 달라지고 목표 마커가 모두 있어야 성공이다.

## 상수와 기록

공식 최종 경로의 기본값을 다음 값으로 고정한다.

- 마커 확인 간격: `1.0`초
- 클릭당 마커 제한시간: `10.0`초
- 최대 재시도: `3`
- 최대 클릭 시도: `4`

성공 결과에는 다음 정보를 남긴다.

- 총 클릭 시도 횟수
- 재시도 횟수
- 각 클릭 결과
- 최종 마커 확인 결과

마지막 실패에는 시도 횟수, 목표 마커, 마지막 복사문을 남긴다. 비밀번호나 접속정보는 기록하지 않는다.

## 오류 처리

- 마커 시간초과: 같은 논리적 클릭을 최대 3회 재시도
- 페이지 만료: 클릭 재시도 금지, 기존 만료 복구 계약으로 전달
- 두 번째 페이지 만료: 기존 계약대로 즉시 실패
- 클립보드·입력·알 수 없는 화면 오류: 재시도 금지, 즉시 실패
- 최대 클릭 횟수 소진: 현재 회사 오류 기록 후 전체 배치 중단

단순 대기시간 연장, 실패 회사 건너뛰기, 별도 보정 runner는 추가하지 않는다.

## 테스트 설계

단위 테스트는 실제 브라우저를 실행하지 않고 클릭 동작과 마커 확인기를 통제한다.

1. 최초 클릭에서 마커가 확인되면 클릭 1회로 종료한다.
2. 최초 클릭이 실패하고 첫 재시도에서 성공하면 클릭 2회로 종료한다.
3. 세 번째 재시도에서 성공하면 총 클릭 4회로 종료한다.
4. 총 4회 모두 마커 시간초과이면 마지막 예외를 발생시킨다.
5. 페이지 만료와 다른 실행 오류는 클릭을 반복하지 않는다.
6. 검색 `absent`와 `ambiguous`는 성공한 종결 상태로 반환한다.
7. 서비스 팝업은 체크박스를 한 번만 누르고 팝업이 남아 있을 때 닫기 클릭만 다시 실행한다.
8. 상세 8개 화면의 좌표, 순서, 마커는 변경되지 않는다.
9. 공식 실행 기본 마커 간격은 1초다.

로컬 검증은 관련 단위 테스트와 전체 CRETOP 단위 테스트로 수행한다. 원격 배포와 실브라우저 검증은 코드 리뷰와 커밋 뒤 주인님이 별도로 지시한 단계에서만 수행한다.

## 최종 경로 병합 위치

- 기준 파일: `scripts/cretop_agent.py`
- 병합 위치: 기존 클릭 직후 개별 마커 확인 호출
- 대체 대상: `클릭 1회 → 마커 확인 1회` 연결을 공통 재시도 계약으로 교체
- 엔트로피: 각 호출부의 반복문을 만들지 않고 하나의 계약을 공유하므로 유지 또는 감소
- 금지: 새 runner, 회사별 예외, 다른 이동 방식, 추가 LLM 호출, 주소 기반 우회
