## 4. 디자인 시스템 (style.css)

| 항목 | 값 |
|------|----|
| 폰트 | Pretendard (CDN: cdn.jsdelivr.net) |
| 주색 | `#1B3A6B` (딥 네이비) |
| 강조색 | `#2563EB` (블루) |
| 배경 교대 | `#F0F4F8` |
| 테이블 테두리 | `#CBD5E1` |
| 포맷 | A4 210×297mm, 여백 18mm |

공통 컴포넌트:
- `.doc-header` — 회사명 + 연구소명 + KOITA 인정번호 + 문서 유형 뱃지
- `.doc-footer` — 페이지번호 + 생성일 + 상태 뱃지
- `.signature-block` — 작성자/확인자/승인자 서명란
- `.timestamp-chain` — 5단계 증빙 체인 시각화 (notified→viewed→performed→signed→approved)
- `.status-badge` — AI초안/검토중/확정 상태 표시
- `.data-table` — 실험 데이터 테이블 (헤더 네이비, 교대 배경)
- `.section-title` — 섹션 번호 + 제목 (좌측 컬러 바)

## 5. 문서별 내용 설계

### 01. 연구개발계획서

개발 Phase: 4

| 섹션 | 내용 |
|------|------|
| 표지 | 과제명, 기간, 연구소장, 승인일, 문서번호 |
| 1. 연구 배경 및 필요성 | 레티놀 CS 12%, 클린뷰티 트렌드, 시장 규모 |
| 2. 기술적 불확실성 | 4개 항목 (추출물선정 / 추출조건 / 제형안정성 / 효능재현성) |
| 3. 기존 기술 대비 차별성 | 단일 추출물 vs 다중+나노제형 |
| 4. 정량 목표 | Elastase ≥50%, DPPH IC50 <100μg/mL, 탄력 ≥12%, 자극지수 <0.3 |
| 5. 추진 일정 | M1~M12 간트 테이블 |
| 6. 투입 인력 | 연구원 3명 역할 배분 |
| 7. 소요 예산 | 인건비/재료비 항목별 |
| 8. 기대 성과 | 특허, 제품화, 세액공제 |
| 서명란 | 작성자, 연구소장, 대표이사 |

### 02. 월간 연구노트 M3 — 1차 추출 실험 ★

개발 Phase: 1 (핵심)

| 섹션 | 내용 |
|------|------|
| 문서 헤더 | 과제명, 작성자(박지은), 작성월(2026.03), M3 |
| 타임스탬프 체인 | 5단계 시각화 바 (알림 3/1 → 열람 3/2 → 수행 3/3~3/28 → 서명 3/29 → 승인 3/31) |
| 이번 달 연구 목표 | 10종×3추출법 30개 시료, TPC 측정, 1차 스크리닝 |
| 수행 내용 | 추출 실험 상세 (실험 조건 테이블 포함) |
| 실험 결과 | 추출 수율 테이블, TPC 측정 테이블, 1차 스크리닝 결과 |
| 기술적 도전 및 해결 | 실패 케이스 (고온 열수 추출 시 색소 용출) + 해결 방법 |
| 차월 계획 | M4 항산화 활성 평가 예고 |
| 서명란 | 박지은 연구원 서명 + 연구소장 승인 |

실험 데이터 (PoC 논문 기반 현실적 수치 사용):
- 추출 수율 테이블: 10종 × 3방법 (에탄올/열수/초음파) × 수율(%)
- TPC 테이블: 상위 10개 시료 TPC (mg GAE/g)
- 1차 스크리닝: TPC 상위 10개 선별 결과

### 03. 연구개발 완료보고서

개발 Phase: 4

| 섹션 | 내용 |
|------|------|
| 1. 과제 개요 | 과제명, 기간, 연구원 목록 |
| 2. 목표 vs 달성도 | 정량 목표별 달성 여부 테이블 |
| 3. 월별 연구 요약 | M1~M12 한 줄 요약 테이블 |
| 4. 최종 결과 | 선정 추출물, 최종 제형, 인체적용 수치 |
| 5. 투입 비용 결산 | 계획 vs 실적 비교 |
| 6. 향후 활용 계획 | 특허 출원, 제품화 일정 |
| 서명란 | 연구원 + 연구소장 + 대표이사 |

### 04. 일반연구 및 인력개발비 명세서

개발 Phase: 9 | 법적 근거: 별지 제3호서식(1)

법정 서식 레이아웃 그대로 재현. 인건비/재료비/외주비 항목별 금액, 공제 대상 금액 산출.

### 05. 연구과제총괄표

개발 Phase: 9 | 법적 근거: 별지 제3호서식 부표(3)

과제별 비용 총괄. 1개 과제 기준.

### 06. 인건비 배분표

개발 Phase: 4

연구원 3명 × 12개월 투입시간 테이블. R&D 전담 비율, 월별 인건비 및 공제 대상액 계산.
